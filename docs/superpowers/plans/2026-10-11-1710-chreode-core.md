# chreode core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `@mindlace/chreode` v0.1.0 (`chreode signoff` + `chreode protect` + `chreode.config.ts`) to public npm, gate chreode itself with it, and move sfhousing from its hand-ported `scripts/signoff.ts` onto it.

**Architecture:** A small ESM TypeScript CLI. Pure modules (config validation, rules → triggers → steps planning, stderr policing, status description, protection payloads) are unit-tested directly. Side-effecting modules (git, gh, the step runner, the machine lock) take injected `Exec`/`Run`/I/O so their logic is unit-testable, and an end-to-end integration test drives the real CLI against a throwaway git repo with a bare `origin` and a recording `gh` shim. `signoff/run.ts` orchestrates: preconditions → merge → base → plan → locked run → clean-tree check → tail (push, status, note).

**Tech Stack:** Node ≥ 22.12 (dev on 24), TypeScript ~6.0 (strict, NodeNext), commander 15, proper-lockfile 4, jiti 2, picomatch 4, vitest 4, eslint 10 + typescript-eslint, prettier 3, tsx (dev only, for the integration test).

**Spec:** `docs/superpowers/specs/2026-10-11-1702-chreode-core-design.md` (read it before starting any task).

## Review Focus

1. **The npm bin is a symlink.** `node_modules/.bin/chreode` points at `dist/cli.js`; a naive `import.meta.url === file://argv[1]` "am I main?" check is false through the symlink, so the CLI would do nothing and exit 0, a gate that passes without running. Expect the CLI to run identically through a symlink. (Task 12 pins it.)
2. **chreode signs itself off, and its test suite spawns `chreode signoff`.** The outer run holds the machine lock while the inner integration runs would wait 60 minutes for it, a deadlock. Inherited `CHREODE_*`/`GIT_*` env (e.g. `CHREODE_FULL=1`) would also change inner behavior. Expect the integration suite to isolate itself (`CHREODE_LOCK_PATH`, scrubbed env). (Tasks 5 and 13 pin it.)
3. **Renames and deletions are changes.** Moving `src/x.ts` to `scratch/x.ts` or deleting a `src/` file must still fire the `src/` triggers. Default `git diff --name-only` collapses a rename to its new path only. Expect both sides of a rename to count. (Task 7 pins it.)
4. **Ctrl-C mid-step.** Steps run in their own (detached) process group so timeouts can kill grandchildren, which means the terminal's SIGINT never reaches them. Expect Ctrl-C to stop the step's whole tree, release the lock, and exit 1, with no orphaned preview server. (Task 6 pins it.)
5. **A step (or `afterMerge`) that modifies the checkout.** `npm install` can rewrite `package-lock.json`; a formatter can rewrite files. Signing off HEAD when the tested tree differs from HEAD is a false green. Expect signoff to refuse to push or post when the tree is dirty or HEAD moved after the steps. (Task 10 pins it.)

## Spec deviations and resolved gaps

- The spec's config example imports `from 'chreode'`; the package is `@mindlace/chreode`, so configs import `from '@mindlace/chreode'`.
- **Tail order is push → status → note** (the spec lists note before status). The note is the incremental cache ("this commit is signed off"); writing it before the status post would let a failed post leave a note that makes the next run say "already signed off" with no status on GitHub.
- Added preconditions: detached HEAD, and `git config user.email` must be set (the status names the signer; failing after the suite would waste the run).
- Added a post-run check: the working tree must still be clean and HEAD unchanged, else exit 1 without pushing/posting (Review Focus 5).
- `--skip <label>` naming an unknown step is an error (a typo would otherwise silently skip nothing while the user believes it skipped).
- `supersededBy` is evaluated against steps that survive `when`/`if`/`--skip`, so `--skip lint` lets `format` run instead of silently dropping formatting too.
- `when: []` is a validation error (the step could never run). Step labels may not contain whitespace (the note is space-joined).
- Base == HEAD prints "already signed off" only when HEAD carries the note; when it comes from the merge-base or `--base`, it prints "nothing to sign off". Both exit 0.
- `CHREODE_LOCK_PATH` env override (not in the spec) exists so the integration test cannot deadlock against a real signoff (Review Focus 2).
- The runner forwards SIGINT/SIGTERM to the step's process group (Review Focus 4).
- **No `v0.1.0` git tag is pushed.** v0.1.0 is hand-published by the user (npm requires the package to exist before a trusted publisher can be attached); pushing `v0.1.0` afterwards would trigger `publish.yml` to republish 0.1.0 and fail red. The first tag pushed is the next version.
- sfhousing gains stderr policing on `test:unit`/`test:e2e` (its old script had none). If the first chreode signoff fails on benign noise, that is a user pause point (allowlisting needs the user's approval).
- `--config <path>` (not in the spec) overrides the config file location (default `<repo root>/chreode.config.ts`); the spec's flag list is amended to match.

```ts
/** A path matcher: a picomatch glob (dotfiles match) or a RegExp tested against the
 *  repo-relative POSIX path. */
export type Matcher = string | RegExp;

/** What a step's `run` function and `if` predicate see. */
export interface StepContext {
  base: string;
  head: string;
  paths: readonly string[];
  triggers: readonly string[];
  isWorktree: boolean;
}

/** First matching rule wins. `triggers: []` means "matched, nothing to run". */
export interface RuleConfig {
  match: Matcher | Matcher[];
  triggers: string[];
}

export interface StepConfig {
  /** Unique, no whitespace. Used by --skip, the note and the status description. */
  label: string;
  run: string | ((ctx: StepContext) => string);
  /** Planned when any listed trigger fired. */
  when: string[];
  if?: (ctx: StepContext) => boolean;
  /** Dropped when any listed step label is also going to run. */
  supersededBy?: string[];
  /** Capture stderr; a clean exit with non-allowlisted stderr fails the step. */
  policeStderr?: boolean;
  /** Hard wall-clock ceiling; the step's process group is SIGKILLed past it. */
  timeoutMs?: number;
}

export interface AllowlistEntry {
  /** A stderr line (ANSI-stripped) matching this pattern is benign. */
  pattern: RegExp;
  /** Why this noise is unavoidable. Required: allowlisting is a reviewed decision. */
  reason: string;
}

export interface ProtectionConfig {
  /** Shallow-merged over the default branch-protection payload. */
  branch?: Record<string, unknown>;
  /** Shallow-merged over the default repository merge settings. */
  repo?: Record<string, unknown>;
}

export interface ChreodeConfig {
  baseBranch?: string;
  statusContext?: string;
  rules?: RuleConfig[];
  steps: StepConfig[];
  /** Runs only when the merge of origin/<baseBranch> actually changed the branch. */
  afterMerge?: string;
  stderrAllowlist?: AllowlistEntry[];
  protection?: ProtectionConfig;
}

export interface ResolvedStep extends StepConfig {
  supersededBy: string[];
  policeStderr: boolean;
  timeoutMs: number;
}

export interface ResolvedConfig {
  baseBranch: string;
  statusContext: string;
  rules: RuleConfig[];
  steps: ResolvedStep[];
  afterMerge: string | null;
  stderrAllowlist: AllowlistEntry[];
  protection: ProtectionConfig;
}

export const DEFAULT_BASE_BRANCH = 'main';
export const DEFAULT_STATUS_CONTEXT = 'chreode/signoff';
export const DEFAULT_TIMEOUT_MS = 10 * 60_000;

/** Identity helper so `chreode.config.ts` gets types. */
export function defineConfig(config: ChreodeConfig): ChreodeConfig {
  return config;
}
```

```ts
import { ConfigError, validateConfig } from './validate.js';

const lint = { label: 'lint', run: 'npm run lint', when: ['lint'] };

function problems(raw: unknown): string[] {
  try {
    validateConfig(raw);
  } catch (err) {
    if (err instanceof ConfigError) return err.problems;
    throw err;
  }
  return [];
}

describe('validateConfig', () => {
  it('fills defaults for a minimal config', () => {
    const config = validateConfig({ steps: [lint] });
    expect(config).toMatchObject({
      baseBranch: 'main',
      statusContext: 'chreode/signoff',
      rules: [],
      afterMerge: null,
      stderrAllowlist: [],
      protection: {}
    });
    expect(config.steps[0]).toMatchObject({
      label: 'lint',
      supersededBy: [],
      policeStderr: false,
      timeoutMs: 600_000
    });
  });

  it('rejects unknown keys at every level', () => {
    expect(
      problems({
        stepz: [],
        steps: [{ ...lint, timeout: 5 }],
        rules: [{ match: 'src/**', triggers: [], trigger: 'x' }]
      })
    ).toEqual(
      expect.arrayContaining([
        'config: unknown key "stepz"',
        'steps[0]: unknown key "timeout"',
        'rules[0]: unknown key "trigger"'
      ])
    );
  });

  it('rejects duplicate labels and labels with whitespace', () => {
    expect(problems({ steps: [lint, lint, { ...lint, label: 'my step' }] })).toEqual([
      'steps[1].label: duplicate label "lint"',
      'steps[2].label: must be non-empty with no whitespace'
    ]);
  });

  it('rejects supersededBy naming a missing step or itself', () => {
    expect(
      problems({
        steps: [
          { ...lint, supersededBy: ['nope'] },
          { label: 'fmt', run: 'x', when: ['f'], supersededBy: ['fmt'] }
        ]
      })
    ).toEqual([
      'step "lint": supersededBy names unknown step "nope"',
      'step "fmt": supersededBy names itself'
    ]);
  });

  it('allows a `when` trigger that no rule emits (the unknown-path fallback can fire it)', () => {
    expect(problems({ rules: [{ match: 'src/**', triggers: ['lint'] }], steps: [{ ...lint, when: ['orphan'] }] })).toEqual([]);
  });

  it('rejects a step that can never run and a malformed run/timeout', () => {
    expect(
      problems({ steps: [{ label: 'a', run: 3, when: [], timeoutMs: -1 }] })
    ).toEqual([
      'steps[0].run: must be a non-empty string or a function',
```

```ts
  DEFAULT_BASE_BRANCH,
  DEFAULT_STATUS_CONTEXT,
  DEFAULT_TIMEOUT_MS,
  type AllowlistEntry,
  type ProtectionConfig,
  type ResolvedConfig,
  type ResolvedStep,
  type RuleConfig,
  type StepConfig
} from './types.js';

export class ConfigError extends Error {
  constructor(readonly problems: string[]) {
    super(`invalid chreode config:\n${problems.map((p) => `  - ${p}`).join('\n')}`);
    this.name = 'ConfigError';
  }
}

const TOP_KEYS = new Set([
  'baseBranch',
  'statusContext',
  'rules',
  'steps',
  'afterMerge',
  'stderrAllowlist',
  'protection'
]);
const RULE_KEYS = new Set(['match', 'triggers']);
const STEP_KEYS = new Set([
  'label',
  'run',
  'when',
  'if',
  'supersededBy',
  'policeStderr',
  'timeoutMs'
]);
const ALLOW_KEYS = new Set(['pattern', 'reason']);
const PROTECTION_KEYS = new Set(['branch', 'repo']);

/** Cross-realm safe: a config evaluated by jiti may not share this realm's RegExp. */
export function isRegExp(v: unknown): v is RegExp {
  return Object.prototype.toString.call(v) === '[object RegExp]';
}

export function isRecord(v: unknown): v is Record<string, unknown> {
  return typeof v === 'object' && v !== null && !Array.isArray(v) && !isRegExp(v);
}

function isNonEmptyString(v: unknown): v is string {
  return typeof v === 'string' && v.length > 0;
}

function isStringArray(v: unknown): v is string[] {
  return Array.isArray(v) && v.every(isNonEmptyString);
}

function isMatcher(v: unknown): boolean {
  return isNonEmptyString(v) || isRegExp(v);
}

function unknownKeys(
  obj: Record<string, unknown>,
  allowed: Set<string>,
  where: string,
  problems: string[]
): void {
  for (const key of Object.keys(obj)) {
    if (!allowed.has(key)) problems.push(`${where}: unknown key "${key}"`);
  }
}

function validateRules(raw: unknown, problems: string[]): RuleConfig[] {
  if (raw === undefined) return [];
  if (!Array.isArray(raw)) {
    problems.push('config.rules: must be an array');
    return [];
  }
  raw.forEach((rule: unknown, i) => {
    const where = `rules[${i}]`;
    if (!isRecord(rule)) {
      problems.push(`${where}: must be an object`);
      return;
    }
    unknownKeys(rule, RULE_KEYS, where, problems);
    const m = rule.match;
    const ok = Array.isArray(m) ? m.length > 0 && m.every(isMatcher) : isMatcher(m);
    if (!ok) {
      problems.push(`${where}.match: must be a glob string, a RegExp, or a non-empty array of them`);
    }
    if (!Array.isArray(rule.triggers) || !rule.triggers.every(isNonEmptyString)) {
      problems.push(
        `${where}.triggers: must be an array of trigger names ([] means "matched, run nothing")`
      );
    }
  });
  return raw as RuleConfig[];
}

function validateSteps(raw: unknown, problems: string[]): ResolvedStep[] {
  if (!Array.isArray(raw)) {
    problems.push('config.steps: must be an array');
    return [];
  }
  const labels = new Set<string>();
  const out: ResolvedStep[] = [];
  raw.forEach((step: unknown, i) => {
    const where = `steps[${i}]`;
    if (!isRecord(step)) {
      problems.push(`${where}: must be an object`);
      return;
    }
    unknownKeys(step, STEP_KEYS, where, problems);
    const label = step.label;
    if (typeof label !== 'string' || !/^\S+$/.test(label)) {
      problems.push(`${where}.label: must be non-empty with no whitespace`);
    } else if (labels.has(label)) {
      problems.push(`${where}.label: duplicate label "${label}"`);
    } else {
      labels.add(label);
    }
    if (!isNonEmptyString(step.run) && typeof step.run !== 'function') {
      problems.push(`${where}.run: must be a non-empty string or a function`);
    }
    if (!isStringArray(step.when) || step.when.length === 0) {
      problems.push(`${where}.when: must be a non-empty array of trigger names`);
    }
    if (step.if !== undefined && typeof step.if !== 'function') {
      problems.push(`${where}.if: must be a function`);
    }
    if (step.supersededBy !== undefined && !isStringArray(step.supersededBy)) {
      problems.push(`${where}.supersededBy: must be an array of step labels`);
    }
    if (step.policeStderr !== undefined && typeof step.policeStderr !== 'boolean') {
      problems.push(`${where}.policeStderr: must be a boolean`);
    }
    const t = step.timeoutMs;
    if (t !== undefined && (typeof t !== 'number' || !Number.isFinite(t) || t <= 0)) {
      problems.push(`${where}.timeoutMs: must be a positive number`);
    }
    out.push({
      ...(step as unknown as StepConfig),
      supersededBy: isStringArray(step.supersededBy) ? step.supersededBy : [],
      policeStderr: step.policeStderr === true,
      timeoutMs: typeof t === 'number' && t > 0 ? t : DEFAULT_TIMEOUT_MS
    });
  });
  for (const step of out) {
    for (const target of step.supersededBy) {
      if (target === step.label) {
        problems.push(`step "${step.label}": supersededBy names itself`);
      } else if (!labels.has(target)) {
        problems.push(`step "${step.label}": supersededBy names unknown step "${target}"`);
      }
    }
  }
  return out;
}

function validateAllowlist(raw: unknown, problems: string[]): AllowlistEntry[] {
  if (raw === undefined) return [];
  if (!Array.isArray(raw)) {
    problems.push('config.stderrAllowlist: must be an array');
    return [];
  }
  raw.forEach((entry: unknown, i) => {
    const where = `stderrAllowlist[${i}]`;
    if (!isRecord(entry)) {
      problems.push(`${where}: must be an object`);
      return;
    }
    unknownKeys(entry, ALLOW_KEYS, where, problems);
    if (!isRegExp(entry.pattern)) problems.push(`${where}.pattern: must be a RegExp`);
    if (!isNonEmptyString(entry.reason)) problems.push(`${where}.reason: must be a non-empty string`);
  });
  return raw as AllowlistEntry[];
}

function validateProtection(raw: unknown, problems: string[]): ProtectionConfig {
  if (raw === undefined) return {};
  if (!isRecord(raw)) {
    problems.push('config.protection: must be an object');
    return {};
  }
  unknownKeys(raw, PROTECTION_KEYS, 'protection', problems);
  for (const key of ['branch', 'repo'] as const) {
    if (raw[key] !== undefined && !isRecord(raw[key])) {
      problems.push(`protection.${key}: must be an object`);
    }
  }
  return raw as ProtectionConfig;
}

export function validateConfig(raw: unknown): ResolvedConfig {
  if (!isRecord(raw)) {
    throw new ConfigError([
      'config must be an object (does chreode.config.ts `export default defineConfig({ ... })`?)'
    ]);
  }
  const problems: string[] = [];
  unknownKeys(raw, TOP_KEYS, 'config', problems);
  for (const key of ['baseBranch', 'statusContext', 'afterMerge'] as const) {
    if (raw[key] !== undefined && !isNonEmptyString(raw[key])) {
      problems.push(`config.${key}: must be a non-empty string`);
    }
  }
  const rules = validateRules(raw.rules, problems);
  const steps = validateSteps(raw.steps, problems);
  const stderrAllowlist = validateAllowlist(raw.stderrAllowlist, problems);
  const protection = validateProtection(raw.protection, problems);
  if (problems.length > 0) throw new ConfigError(problems);
  return {
    baseBranch: (raw.baseBranch as string | undefined) ?? DEFAULT_BASE_BRANCH,
    statusContext: (raw.statusContext as string | undefined) ?? DEFAULT_STATUS_CONTEXT,
    rules,
    steps,
    afterMerge: (raw.afterMerge as string | undefined) ?? null,
    stderrAllowlist,
    protection
  };
}
```

```ts
import picomatch from 'picomatch';
import type {
  Matcher,
  ResolvedConfig,
  ResolvedStep,
  RuleConfig,
  StepContext
} from '../config/types.js';

export class PlanError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'PlanError';
  }
}

export interface PlanInput {
  paths: readonly string[];
  full: boolean;
  skip: readonly string[];
  base: string;
  head: string;
  isWorktree: boolean;
}

export interface PlannedStep {
  label: string;
  command: string;
  policeStderr: boolean;
  timeoutMs: number;
}

export type SkipReason =
  | { kind: 'not-triggered' }
  | { kind: 'if-false' }
  | { kind: 'skip-flag' }
  | { kind: 'superseded'; by: string };

export interface Plan {
  triggers: string[];
  /** Changed paths no rule matched; each one fired every trigger. */
  unmatched: string[];
  steps: PlannedStep[];
  skipped: { label: string; reason: SkipReason }[];
  /** Steps that would have run but for --skip: these go in the status description. */
  skippedByFlag: string[];
}

function tester(m: Matcher): (path: string) => boolean {
  if (typeof m === 'string') return picomatch(m, { dot: true });
  return (path) => {
    // A /g or /y RegExp carries lastIndex between calls; reset so every path is tested fresh.
    m.lastIndex = 0;
    return m.test(path);
  };
}

export function matchRule(path: string, rules: readonly RuleConfig[]): RuleConfig | null {
  for (const rule of rules) {
    const matchers = Array.isArray(rule.match) ? rule.match : [rule.match];
    if (matchers.some((m) => tester(m)(path))) return rule;
  }
  return null;
}

export function allTriggers(steps: readonly ResolvedStep[]): string[] {
  return [...new Set(steps.flatMap((s) => s.when))].sort();
}

/** Rules can only make a run smaller by matching: an unmatched path fires everything. */
export function fireTriggers(
  paths: readonly string[],
  rules: readonly RuleConfig[],
  steps: readonly ResolvedStep[]
): { triggers: string[]; unmatched: string[] } {
  const fired = new Set<string>();
  const unmatched: string[] = [];
  for (const path of paths) {
    const rule = matchRule(path, rules);
    const triggers = rule === null ? allTriggers(steps) : rule.triggers;
    if (rule === null) unmatched.push(path);
    for (const t of triggers) fired.add(t);
  }
  return { triggers: [...fired].sort(), unmatched };
}

export function planSignoff(config: ResolvedConfig, input: PlanInput): Plan {
  const known = config.steps.map((s) => s.label);
  const unknownSkips = input.skip.filter((l) => !known.includes(l));
  if (unknownSkips.length > 0) {
    throw new PlanError(
      `--skip names unknown step(s): ${unknownSkips.join(', ')} (known: ${known.join(', ')})`
    );
  }
  const { triggers, unmatched } = input.full
    ? { triggers: allTriggers(config.steps), unmatched: [] }
    : fireTriggers(input.paths, config.rules, config.steps);
  const ctx: StepContext = {
    base: input.base,
    head: input.head,
    paths: input.paths,
    triggers,
    isWorktree: input.isWorktree
  };
  const fired = new Set(triggers);
  const skipSet = new Set(input.skip);
  const skipped: Plan['skipped'] = [];
  const skippedByFlag: string[] = [];
  const survivors: ResolvedStep[] = [];
  for (const step of config.steps) {
    if (!step.when.some((t) => fired.has(t))) {
      skipped.push({ label: step.label, reason: { kind: 'not-triggered' } });
    } else if (step.if && !step.if(ctx)) {
      skipped.push({ label: step.label, reason: { kind: 'if-false' } });
    } else if (skipSet.has(step.label)) {
      skipped.push({ label: step.label, reason: { kind: 'skip-flag' } });
      skippedByFlag.push(step.label);
    } else {
      survivors.push(step);
    }
  }
  const surviving = new Set(survivors.map((s) => s.label));
  const steps: PlannedStep[] = [];
  for (const step of survivors) {
    const by = step.supersededBy.find((l) => surviving.has(l));
    if (by !== undefined) {
      skipped.push({ label: step.label, reason: { kind: 'superseded', by } });
      continue;
    }
    const command = typeof step.run === 'function' ? step.run(ctx) : step.run;
    if (typeof command !== 'string' || command.trim() === '') {
      throw new PlanError(`step "${step.label}": run() must return a non-empty command`);
    }
    steps.push({
      label: step.label,
      command,
      policeStderr: step.policeStderr,
      timeoutMs: step.timeoutMs
    });
  }
  return { triggers, unmatched, steps, skipped, skippedByFlag };
}

export function describeSkip(reason: SkipReason): string {
  switch (reason.kind) {
    case 'not-triggered':
      return 'no relevant changes';
    case 'if-false':
      return '`if` returned false';
    case 'skip-flag':
```

```ts
import type { AllowlistEntry } from '../config/types.js';

// ANSI SGR color codes must not defeat allowlist matching. The escape character is built at
// runtime so no control character appears in source (keeps no-control-regex quiet).
const ANSI_SGR = new RegExp(`${String.fromCharCode(27)}\\[[0-9;]*m`, 'g');

/** Classify captured stderr line by line: blank and allowlisted lines are benign,
 *  everything else is returned ANSI-stripped. */
export function policeStderr(
  buffer: string,
  allowlist: readonly AllowlistEntry[]
): { offendingLines: string[] } {
  const offendingLines = buffer
    .split(/\r?\n/)
    .map((line) => line.replace(ANSI_SGR, ''))
    .filter((line) => line.trim() !== '')
    .filter(
      (line) =>
        !allowlist.some((entry) => {
          entry.pattern.lastIndex = 0;
          return entry.pattern.test(line);
        })
    );
  return { offendingLines };
}

export type PolicedOutcome =
  | { kind: 'pass' }
  | { kind: 'fail-exit'; rawStderr: string }
  | { kind: 'fail-stderr'; offendingLines: string[] };

/** A non-zero/null exit is a real failure (surface everything). A clean exit with
 *  non-allowlisted stderr is a policy failure (surface just the offending lines). */
export function decidePolicedOutcome(
  result: { code: number | null; stderr?: string },
  allowlist: readonly AllowlistEntry[]
): PolicedOutcome {
  const buffer = result.stderr ?? '';
  if (result.code !== 0) return { kind: 'fail-exit', rawStderr: buffer };
  const { offendingLines } = policeStderr(buffer, allowlist);
  if (offendingLines.length > 0) return { kind: 'fail-stderr', offendingLines };
  return { kind: 'pass' };
}
```

```ts
import os from 'node:os';
import path from 'node:path';
import lockfile from 'proper-lockfile';

// Steps hold gigabytes. Several agents in parallel worktrees running a suite at once swap
// the machine to death and produce spurious failures, and the contended resource is the
// machine, not the repo, so every chreode repo on the box shares ONE lock.
//
// A live holder refreshes the lock mtime every UPDATE; a holder that dies stops refreshing,
// so the lock goes stale after STALE and the next waiter steals it.
export const LOCK_STALE_MS = 30_000;
export const LOCK_UPDATE_MS = 10_000;
export const LOCK_POLL_MS = 2_000;
export const LOCK_MAX_WAIT_MS = 60 * 60_000;

export type Release = () => Promise<void>;

export interface MachineLock {
  /** Resolves to a release fn once held; while held elsewhere, logs once and polls. */
  acquire(): Promise<Release>;
}

export interface RetryingLockDeps {
  /** One attempt; must reject with an `ELOCKED`-coded error when held. */
  tryLock: () => Promise<Release>;
  label: string;
  lockPath: string;
  pollMs: number;
  maxWaitMs: number;
  now: () => number;
  sleep: (ms: number) => Promise<void>;
  log: (msg: string) => void;
  /** One-line remedy appended to the timeout error. */
  hint?: string;
}

/** Poll-until-free around a one-shot lock. All I/O injected so the retry/log/timeout logic
 *  is testable without the filesystem or real timers. */
export function createRetryingLock(deps: RetryingLockDeps): MachineLock {
  return {
    async acquire(): Promise<Release> {
      const deadline = deps.now() + deps.maxWaitMs;
      let logged = false;
      for (;;) {
        try {
          return await deps.tryLock();
        } catch (err) {
          if ((err as { code?: string }).code !== 'ELOCKED') throw err;
          if (!logged) {
            deps.log(`[chreode] another run holds the ${deps.label} lock; waiting…`);
            logged = true;
          }
          if (deps.now() >= deadline) {
            const hint = deps.hint ? ` ${deps.hint}` : '';
            throw new Error(
              `[chreode] timed out after ${Math.round(deps.maxWaitMs / 60_000)}m waiting for ` +
                `the ${deps.label} lock (${deps.lockPath}).${hint}`,
              { cause: err }
            );
          }
          await deps.sleep(deps.pollMs);
        }
      }
    }
  };
}

/** proper-lockfile at a fixed path, with stale-steal. */
export function fileLock(opts: {
  label: string;
  lockPath: string;
  staleMs?: number;
  updateMs?: number;
  pollMs?: number;
  maxWaitMs?: number;
  hint?: string;
  log?: (msg: string) => void;
}): MachineLock {
  return createRetryingLock({
    tryLock: () =>
      lockfile.lock(opts.lockPath, {
        realpath: false, // the target need not exist; the lock is the `${lockPath}.lock` dir
        stale: opts.staleMs ?? LOCK_STALE_MS,
        update: opts.updateMs ?? LOCK_UPDATE_MS,
        retries: 0, // we own the retry loop so we can log once and bound the wait
        // The default handler throws from a timer: a stalled mtime refresh (laptop sleep) would crash
        // chreode uncaught and orphan the detached step group. Log and carry on instead.
        onCompromised: (err) => console.error(`[chreode] lock compromised: ${err.message}`)
      }),
    label: opts.label,
    lockPath: opts.lockPath,
    pollMs: opts.pollMs ?? LOCK_POLL_MS,
    maxWaitMs: opts.maxWaitMs ?? LOCK_MAX_WAIT_MS,
    now: () => Date.now(),
    sleep: (ms) => new Promise((resolve) => setTimeout(resolve, ms)),
    log: opts.log ?? ((msg) => console.log(msg)),
    hint: opts.hint
  });
}

/** `CHREODE_LOCK_PATH` exists for test isolation: chreode's own suite runs `chreode signoff`
 *  while an outer signoff holds the real lock. */
export function defaultLockPath(env: NodeJS.ProcessEnv = process.env): string {
  return env.CHREODE_LOCK_PATH || path.join(os.tmpdir(), 'chreode-signoff.lock');
}

export function signoffLock(env: NodeJS.ProcessEnv = process.env): MachineLock {
  return fileLock({
    label: 'signoff',
    lockPath: defaultLockPath(env),
    hint: 'The holder is another chreode signoff on this machine (any repo). Do not kill it; wait it out.'
  });
}
```

```ts
import type { AllowlistEntry } from '../config/types.js';
import type { MachineLock } from '../lock/machine-lock.js';
import type { PlannedStep } from '../signoff/plan.js';
import { decidePolicedOutcome } from './stderr.js';

export interface RunResult {
  /** Exit code, or null when killed by a signal. */
  code: number | null;
  timedOut: boolean;
  interrupted: boolean;
  /** Present only when captureStderr was set. */
  stderr?: string;
}

export interface SignalSource {
  on(event: 'SIGINT' | 'SIGTERM', fn: () => void): unknown;
  off(event: 'SIGINT' | 'SIGTERM', fn: () => void): unknown;
}

export interface RunOptions {
  /** stdout stays live; stderr is piped, buffered and returned. */
  captureStderr?: boolean;
  env?: NodeJS.ProcessEnv;
  cwd?: string;
  /** Where SIGINT/SIGTERM arrive; defaults to the process. Injectable for tests. */
  signals?: SignalSource;
}

/** After exit, how long to wait for a captured stderr pipe to drain. A grandchild that
 *  inherited the pipe can hold it open; this bounds the wait. */
const STDERR_DRAIN_MS = 2_000;

/**
 * Run a shell command with a hard wall-clock timeout. The command runs in its OWN process
 * group (detached) so a timeout can SIGKILL the whole tree, not just the wrapping shell.
 * Being in its own group, it no longer receives the terminal's Ctrl-C, so SIGINT/SIGTERM
 * delivered to us are forwarded to the group. Never rejects.
 */
export function runWithTimeout(
  cmd: string,
  timeoutMs: number,
  opts: RunOptions = {}
): Promise<RunResult> {
  const capture = opts.captureStderr ?? false;
  const signals: SignalSource = opts.signals ?? process;
  return new Promise((resolve) => {
    const child = spawn(cmd, {
      shell: true,
      stdio: capture ? ['inherit', 'inherit', 'pipe'] : 'inherit',
      detached: true,
      env: opts.env ?? process.env,
      cwd: opts.cwd
    });
    let stderrBuf = '';
    let stderrEnded = !capture || child.stderr === null;
    let exitCode: number | null | undefined;
    let timedOut = false;
    let interrupted = false;
    let settled = false;

    const killGroup = (signal: NodeJS.Signals) => {
      try {
        if (child.pid !== undefined) process.kill(-child.pid, signal);
      } catch {
        // Group already gone.
      }
    };
    const onSignal = () => {
      interrupted = true;
      killGroup('SIGTERM');
    };
    const timer = setTimeout(() => {
      timedOut = true;
      killGroup('SIGKILL');
    }, timeoutMs);
    signals.on('SIGINT', onSignal);
    signals.on('SIGTERM', onSignal);

    const finish = (code: number | null) => {
      if (settled) return;
      settled = true;
      clearTimeout(timer);
      signals.off('SIGINT', onSignal);
      signals.off('SIGTERM', onSignal);
      resolve({ code, timedOut, interrupted, stderr: capture ? stderrBuf : undefined });
    };

    if (capture && child.stderr) {
      // setEncoding decodes through a StringDecoder, so a multi-byte character split across
      // chunks is not corrupted.
      child.stderr.setEncoding('utf8');
      child.stderr.on('data', (chunk: string) => {
        stderrBuf += chunk;
      });
      child.stderr.on('end', () => {
        stderrEnded = true;
        if (exitCode !== undefined) finish(exitCode);
      });
    }
    child.on('exit', (code) => {
      exitCode = code;
      if (stderrEnded) finish(code);
      else setTimeout(() => finish(code), STDERR_DRAIN_MS).unref();
    });
    child.on('error', () => finish(1));
  });
}

export class StepFailure extends Error {
  constructor(
    readonly label: string,
    message: string
  ) {
    super(message);
    this.name = 'StepFailure';
  }
}

function formatDuration(ms: number): string {
  return ms < 60_000 ? `${Math.round(ms / 1000)}s` : `${Math.round(ms / 60_000)}m`;
}

export function timeoutMessage(label: string, timeoutMs: number): string {
  return (
    `\n[chreode] TIMED OUT at: ${label} after ${formatDuration(timeoutMs)}. Suspect a ` +
    `contending process or a genuinely slow machine. Killed the step's process tree.`
  );
}

export interface StepRunOptions {
  allowStderr: boolean;
  allowlist: readonly AllowlistEntry[];
  env?: NodeJS.ProcessEnv;
  log?: (m: string) => void;
  error?: (m: string) => void;
  writeStderr?: (s: string) => void;
  runImpl?: (cmd: string, timeoutMs: number, opts: RunOptions) => Promise<RunResult>;
}

/** Run one planned step. Every failure throws StepFailure so the caller's `finally`
 *  releases the lock before the run exits. */
export async function runStep(step: PlannedStep, opts: StepRunOptions): Promise<void> {
  const log = opts.log ?? ((m: string) => console.log(m));
  const error = opts.error ?? ((m: string) => console.error(m));
  const writeStderr = opts.writeStderr ?? ((s: string) => void process.stderr.write(s));
  const runImpl = opts.runImpl ?? runWithTimeout;

  log(`\n[chreode] ${step.label}: ${step.command}`);
  const r = await runImpl(step.command, step.timeoutMs, {
    captureStderr: step.policeStderr,
    env: opts.env
  });

  if (r.timedOut) {
    if (r.stderr) writeStderr(r.stderr);
    error(timeoutMessage(step.label, step.timeoutMs));
    throw new StepFailure(step.label, `${step.label} timed out`);
  }
  if (r.interrupted) {
    if (r.stderr) writeStderr(r.stderr);
    error(`\n[chreode] INTERRUPTED at: ${step.label}`);
    throw new StepFailure(step.label, `${step.label} interrupted`);
  }
  if (!step.policeStderr) {
    if (r.code !== 0) {
      error(`\n[chreode] FAILED at: ${step.label} (exit ${r.code})`);
      throw new StepFailure(step.label, `${step.label} failed`);
    }
    return;
  }

  const outcome = decidePolicedOutcome({ code: r.code, stderr: r.stderr }, opts.allowlist);
  if (outcome.kind === 'fail-exit') {
    if (outcome.rawStderr) writeStderr(outcome.rawStderr);
    error(`\n[chreode] FAILED at: ${step.label} (exit ${r.code})`);
    throw new StepFailure(step.label, `${step.label} failed`);
  }
  if (outcome.kind === 'fail-stderr') {
    if (opts.allowStderr) {
      error(`\n[chreode] ${step.label} wrote unexpected stderr, allowed by --allow-stderr:`);
      for (const line of outcome.offendingLines) writeStderr(`${line}\n`);
      return;
    }
    error(
      `\n[chreode] FAILED at: ${step.label}: it exited 0 but wrote unexpected stderr.\n` +
        `[chreode] A passing step that logs errors is still a failure: fix it at the source.\n` +
        `[chreode] Allowlisting genuinely benign noise is a reviewed change to stderrAllowlist\n` +
        `[chreode] in chreode.config.ts, with a reason. --allow-stderr bypasses for one run.\n` +
        `[chreode] Offending lines:`
    );
    for (const line of outcome.offendingLines) writeStderr(`${line}\n`);
    throw new StepFailure(step.label, `${step.label} wrote unexpected stderr`);
  }
}

/** Run the plan holding the machine lock; an empty plan touches no lock. The lock is
 *  released on every exit path. */
export async function runSteps(
  steps: readonly PlannedStep[],
  lock: MachineLock,
  run: (step: PlannedStep) => Promise<void>
): Promise<void> {
  if (steps.length === 0) return;
  const release = await lock.acquire();
  try {
    for (const step of steps) await run(step);
  } finally {
    await release();
  }
}
```

```ts
import type { Exec } from '../../src/run/exec.js';

export type Response = string | Error | Array<string | Error>;

/** A scripted Exec. Keys are `file arg1 arg2 …`. An array response is consumed in order and
 *  its last element repeats. An unscripted command throws (callers that tolerate failure,
 *  like "no upstream", see it as a failure). */
export function fakeExec(responses: Record<string, Response>): { exec: Exec; calls: string[] } {
  const calls: string[] = [];
  const queues = new Map(
    Object.entries(responses).map(([key, value]) => [key, Array.isArray(value) ? [...value] : [value]])
  );
  const exec: Exec = (file, args) => {
    const key = [file, ...args].join(' ');
    calls.push(key);
    const queue = queues.get(key);
    if (!queue || queue.length === 0) throw new Error(`unexpected exec: ${key}`);
    const next = queue.length > 1 ? queue.shift()! : queue[0]!;
    if (next instanceof Error) throw next;
    return next;
  };
  return { exec, calls };
}
```

```ts
  execSync(command, { stdio: 'inherit', env: env ?? process.env });
};

    .map((s) => s.trim())
    .filter(Boolean);
```

```ts
import { defaultExec, lines, type Exec } from '../run/exec.js';

/** Successful signoffs are recorded as notes under refs/notes/chreode. */
export const NOTES_REF = 'chreode';

export interface BaseInfo {
  base: string;
  head: string;
  source: 'note' | 'merge-base';
}

export function hasNote(sha: string, exec: Exec = defaultExec): boolean {
  try {
    exec('git', ['notes', `--ref=${NOTES_REF}`, 'show', sha]);
    return true;
  } catch {
    return false;
  }
}

/** The nearest commit on this branch (not on origin/<baseBranch>) carrying a signoff note;
 *  else the merge-base with origin/<baseBranch>. */
export function resolveBase(baseBranch: string, exec: Exec = defaultExec): BaseInfo {
  const head = exec('git', ['rev-parse', 'HEAD']).trim();
  const upstream = `origin/${baseBranch}`;
  for (const sha of lines(exec('git', ['rev-list', '--topo-order', 'HEAD', `^${upstream}`]))) {
    if (hasNote(sha, exec)) return { base: sha, head, source: 'note' };
  }
  return { base: exec('git', ['merge-base', 'HEAD', upstream]).trim(), head, source: 'merge-base' };
}

export function resolveRef(ref: string, exec: Exec = defaultExec): string {
  return exec('git', ['rev-parse', '--verify', `${ref}^{commit}`]).trim();
}

/** Paths changed between base and head. --no-renames lists both sides of a rename, so a
 *  file moved out of a rule's reach still fires that rule; deletions are included. */
export function committedPaths(base: string, head: string, exec: Exec = defaultExec): string[] {
  if (base === head) return [];
  return lines(exec('git', ['diff', '--name-only', '--no-renames', `${base}..${head}`]));
}

export function isWorktree(exec: Exec = defaultExec): boolean {
  const [gitDir, commonDir] = lines(
    exec('git', ['rev-parse', '--path-format=absolute', '--git-dir', '--git-common-dir'])
  );
  return gitDir !== commonDir;
}

export function writeNote(sha: string, ranLabels: readonly string[], exec: Exec = defaultExec): void {
  const summary = ranLabels.length > 0 ? ranLabels.join(' ') : 'no-op';
  exec('git', ['notes', `--ref=${NOTES_REF}`, 'add', '-f', '-m', summary, sha]);
}
```

```ts
import { defaultExec, type Exec } from '../run/exec.js';

export type MergeOutcome =
  | { kind: 'skipped' }
  | { kind: 'up-to-date' }
  | { kind: 'merged' }
  | { kind: 'conflict' }
  | { kind: 'failed'; message: string };

/**
 * Fold the latest origin/<baseBranch> into the branch so what is signed off is what will
 * land. Merge, never rebase: existing SHAs (and their notes) survive and the push stays a
 * fast-forward. On conflict the merge is left in progress for the user to resolve.
 */
export function mergeBaseBranch(
  baseBranch: string,
  opts: { noMerge: boolean },
  exec: Exec = defaultExec,
  warn: (m: string) => void = (m) => console.warn(m)
): MergeOutcome {
  if (opts.noMerge) return { kind: 'skipped' };
  const upstream = `origin/${baseBranch}`;
  try {
    exec('git', ['fetch', 'origin', baseBranch]);
  } catch (err) {
    warn(
      `[chreode] git fetch origin ${baseBranch} failed (${(err as Error).message.trim()}); ` +
        `continuing with the local view of ${upstream}`
    );
  }
  if (exec('git', ['rev-list', `HEAD..${upstream}`]).trim() === '') return { kind: 'up-to-date' };
  try {
    exec('git', ['merge', '--no-edit', upstream]);
  } catch (err) {
    try {
      exec('git', ['rev-parse', '-q', '--verify', 'MERGE_HEAD']);
      return { kind: 'conflict' };
    } catch {
      return { kind: 'failed', message: (err as Error).message.trim() };
    }
  }
  return { kind: 'merged' };
}
```

```ts
import { defaultExec, type Exec } from '../run/exec.js';

export class PreconditionError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'PreconditionError';
  }
}

export interface Preconditions {
  branch: string;
  /** git user.email: named in the status description. */
  signer: string;
}

export function checkPreconditions(baseBranch: string, exec: Exec = defaultExec): Preconditions {
  if (exec('git', ['status', '--porcelain']).trim() !== '') {
    throw new PreconditionError('working tree is dirty; commit or stash before signing off');
  }
  let branch: string;
  try {
    branch = exec('git', ['symbolic-ref', '-q', '--short', 'HEAD']).trim();
  } catch {
    throw new PreconditionError('HEAD is detached; check out a branch before signing off');
  }
  if (branch === baseBranch) {
    throw new PreconditionError(
      `on ${baseBranch} itself; signoff is for branches that merge into ${baseBranch}`
    );
  }
  let behind = '';
  try {
    behind = exec('git', ['rev-list', 'HEAD..@{u}']).trim();
  } catch {
    // No upstream yet: nothing to be behind.
  }
  if (behind !== '') {
    throw new PreconditionError('HEAD is behind its upstream; pull before signing off');
  }
  try {
    exec('gh', ['auth', 'status']);
  } catch {
```

```ts
import { defaultExec, type Exec } from '../run/exec.js';

/** GitHub rejects longer descriptions with a 422; truncate rather than fail the post. */
export const STATUS_DESCRIPTION_MAX = 140;

/** Honest about --skip, so a skipped required step cannot wear the same green as a full run. */
export function statusDescription(signer: string, skipped: readonly string[]): string {
  const desc =
    skipped.length === 0
      ? `signed off by ${signer}`
      : `signed off by ${signer} (skipped: ${skipped.join(', ')})`;
  if (desc.length <= STATUS_DESCRIPTION_MAX) return desc;
  return `${desc.slice(0, STATUS_DESCRIPTION_MAX - 3)}...`;
}

export interface RepoInfo {
  owner: string;
  name: string;
}

export function parseRepo(s: string): RepoInfo {
  const m = /^([\w.-]+)\/([\w.-]+)$/.exec(s);
  if (!m) throw new Error(`repo must look like owner/name, got "${s}"`);
  return { owner: m[1]!, name: m[2]! };
}

export function repoInfo(exec: Exec = defaultExec): RepoInfo {
  const parsed = JSON.parse(exec('gh', ['repo', 'view', '--json', 'owner,name'])) as {
    owner: { login: string };
    name: string;
  };
  return { owner: parsed.owner.login, name: parsed.name };
}

export function statusArgs(
  repo: RepoInfo,
  sha: string,
  context: string,
  description: string
): string[] {
  return [
    'api',
    '-X',
    'POST',
    `repos/${repo.owner}/${repo.name}/statuses/${sha}`,
    '-f',
    'state=success',
    '-f',
    `context=${context}`,
    '-f',
    `description=${description}`
  ];
}

export function postStatus(
  repo: RepoInfo,
  sha: string,
  context: string,
  description: string,
  exec: Exec = defaultExec
): void {
  exec('gh', statusArgs(repo, sha, context, description));
}

export function prUrl(exec: Exec = defaultExec): string | null {
  try {
    return (JSON.parse(exec('gh', ['pr', 'view', '--json', 'url'])) as { url: string }).url;
  } catch {
    return null;
  }
}
```

```ts
import { writeNote } from '../git/change-set.js';
import { postStatus, prUrl, statusDescription, type RepoInfo } from '../github/status.js';
import { defaultExec, defaultRun, type Exec, type Run } from '../run/exec.js';

export interface TailEffects {
  push(): void;
  postStatus(sha: string, description: string): void;
  writeNote(sha: string, ranLabels: readonly string[]): void;
  prUrl(): string | null;
}

export interface TailWork {
  sha: string;
  signer: string;
  noPush: boolean;
  ranLabels: readonly string[];
  skippedByFlag: readonly string[];
  context: string;
}

/**
 * After every step passed: push, post the status, then write the note. The note is the
 * incremental cache ("this commit is signed off"), so it goes last: a failed post must not
 * leave a note that makes the next run a no-op with no status on GitHub.
 */
export function runTail(
  work: TailWork,
  effects: TailEffects,
  log: (m: string) => void = (m) => console.log(m)
): void {
  if (work.noPush) {
    log('[chreode] --no-push: not pushing (the commit must already be on origin)');
  } else {
    log('\n[chreode] git push -u origin HEAD');
    effects.push();
  }
  effects.postStatus(work.sha, statusDescription(work.signer, work.skippedByFlag));
  log(`[chreode] ${work.context} = success posted on ${work.sha}`);
  effects.writeNote(work.sha, work.ranLabels);
  const url = effects.prUrl();
  if (url) log(`[chreode] PR: ${url}`);
}

export function defaultTailEffects(
  repo: () => RepoInfo,
  context: string,
  exec: Exec = defaultExec,
  run: Run = defaultRun
): TailEffects {
  return {
    push: () => run('git push -u origin HEAD'),
    postStatus: (sha, description) => postStatus(repo(), sha, context, description, exec),
    writeNote: (sha, labels) => writeNote(sha, labels, exec),
    prUrl: () => prUrl(exec)
  };
}
```

```ts
import type { ResolvedConfig } from '../config/types.js';
import {
  committedPaths,
  isWorktree,
  resolveBase,
  resolveRef,
  type BaseInfo
} from '../git/change-set.js';
import { mergeBaseBranch } from '../git/merge.js';
import { repoInfo, type RepoInfo } from '../github/status.js';
import { signoffLock, type MachineLock } from '../lock/machine-lock.js';
import { defaultExec, defaultRun, type Exec, type Run } from '../run/exec.js';
import { StepFailure, runStep, runSteps } from '../run/step.js';
import { PlanError, describeSkip, planSignoff, type Plan, type PlannedStep } from './plan.js';
import { PreconditionError, checkPreconditions, type Preconditions } from './preconditions.js';
import { defaultTailEffects, runTail, type TailEffects } from './tail.js';

export interface SignoffOptions {
  full: boolean;
  dryRun: boolean;
  noMerge: boolean;
  noPush: boolean;
  allowStderr: boolean;
  base: string | null;
  skip: string[];
}

export interface SignoffDeps {
  exec: Exec;
  run: Run;
  lock: MachineLock;
  runStep: (step: PlannedStep) => Promise<void>;
  tail: TailEffects;
  log: (m: string) => void;
  warn: (m: string) => void;
  error: (m: string) => void;
}

function defaultDeps(config: ResolvedConfig, opts: SignoffOptions): SignoffDeps {
  // Children can detect the gate (e.g. to quiet build-tool stderr) via CHREODE_SIGNOFF=1.
  const env = { ...process.env, CHREODE_SIGNOFF: '1' };
  let repo: RepoInfo | null = null;
  const getRepo = () => (repo ??= repoInfo(defaultExec));
  return {
    exec: defaultExec,
    run: (command) => defaultRun(command, env),
    lock: signoffLock(),
    runStep: (step) =>
      runStep(step, { allowStderr: opts.allowStderr, allowlist: config.stderrAllowlist, env }),
    tail: defaultTailEffects(getRepo, config.statusContext),
    log: (m) => console.log(m),
    warn: (m) => console.warn(m),
    error: (m) => console.error(m)
  };
}

function message(err: unknown): string {
  return err instanceof Error ? err.message : String(err);
}

export function printPlan(
  plan: Plan,
  where: { base: string; head: string; paths: readonly string[]; full: boolean },
  log: (m: string) => void
): void {
  log(`[chreode] base=${where.base} head=${where.head}${where.full ? ' (--full)' : ''}`);
  log(`[chreode] changed paths (${where.paths.length}):`);
  for (const p of where.paths) log(`  ${p}`);
  if (plan.unmatched.length > 0) {
    log(`[chreode] matched no rule, so every trigger fired: ${plan.unmatched.join(', ')}`);
  }
  log(`[chreode] triggers: ${plan.triggers.length > 0 ? plan.triggers.join(', ') : '(none)'}`);
  log(
    `[chreode] plan: ${plan.steps.length > 0 ? plan.steps.map((s) => s.label).join(', ') : '(no steps: a no-op signoff)'}`
  );
  for (const { label, reason } of plan.skipped) {
    log(`[chreode] skipping ${label} (${describeSkip(reason)})`);
  }
}

export async function runSignoff(
  config: ResolvedConfig,
  opts: SignoffOptions,
  overrides: Partial<SignoffDeps> = {}
): Promise<number> {
  const d: SignoffDeps = { ...defaultDeps(config, opts), ...overrides };
  const baseBranch = config.baseBranch;

  // 1. Preconditions
  let pre: Preconditions;
  try {
    pre = checkPreconditions(baseBranch, d.exec);
  } catch (err) {
    if (err instanceof PreconditionError) {
      d.error(`[chreode] ${err.message}`);
      return 1;
    }
    throw err;
  }

  // 2. Merge
  const merge = mergeBaseBranch(baseBranch, { noMerge: opts.noMerge }, d.exec, d.warn);
  if (merge.kind === 'conflict') {
    d.error(
      `\n[chreode] merging origin/${baseBranch} hit a conflict. The merge is in progress.\n` +
        `Resolve it, run \`git commit --no-edit\`, then re-run signoff.\n` +
        `To bail out: \`git merge --abort\`.`
    );
    return 1;
  }
  if (merge.kind === 'failed') {
    d.error(`[chreode] merging origin/${baseBranch} failed: ${merge.message}`);
    return 1;
  }
  if (merge.kind === 'merged') {
    d.log(`[chreode] merged origin/${baseBranch} into ${pre.branch}`);
    if (config.afterMerge) {
      d.log(`[chreode] afterMerge: ${config.afterMerge}`);
      try {
        d.run(config.afterMerge);
      } catch {
        d.error('[chreode] afterMerge failed');
        return 1;
      }
    }
  }

  // 3. Resolve base
  const head = d.exec('git', ['rev-parse', 'HEAD']).trim();
  let base: BaseInfo['base'];
  let source: BaseInfo['source'] | 'flag';
  try {
    if (opts.base !== null) {
      base = resolveRef(opts.base, d.exec);
      source = 'flag';
    } else {
      ({ base, source } = resolveBase(baseBranch, d.exec));
    }
  } catch (err) {
    d.error(`[chreode] could not resolve the base: ${message(err)}`);
    return 1;
  }
  if (!opts.full && base === head) {
    d.log(
      source === 'note'
        ? `[chreode] already signed off at ${head}; nothing to do (--full re-runs everything)`
        : `[chreode] nothing to sign off: ${base} is HEAD`
    );
    return 0;
  }

  // 4. Plan
  const paths = committedPaths(base, head, d.exec);
  let plan: Plan;
  try {
    plan = planSignoff(config, {
      paths,
      full: opts.full,
      skip: opts.skip,
      base,
      head,
      isWorktree: isWorktree(d.exec)
    });
  } catch (err) {
    if (err instanceof PlanError) {
      d.error(`[chreode] ${err.message}`);
      return 1;
    }
    throw err;
  }
  printPlan(plan, { base, head, paths, full: opts.full }, d.log);
  if (opts.dryRun) {
    d.log('[chreode] --dry-run: stopping before the run');
    return 0;
  }

  // 5. Run
  try {
    await runSteps(plan.steps, d.lock, d.runStep);
  } catch (err) {
    if (!(err instanceof StepFailure)) d.error(`[chreode] ${message(err)}`);
    return 1;
  }

  // What was tested must be exactly HEAD.
  const dirty = d.exec('git', ['status', '--porcelain']).trim();
  const after = d.exec('git', ['rev-parse', 'HEAD']).trim();
  if (dirty !== '' || after !== head) {
    d.error(
      `[chreode] the steps changed the checkout (${dirty !== '' ? 'the working tree is dirty' : `HEAD moved to ${after}`}); ` +
        `commit the change and re-run signoff. Nothing was posted.`
    );
    return 1;
  }

  // 6. Tail
  try {
    runTail(
      {
        sha: head,
        signer: pre.signer,
        noPush: opts.noPush,
        ranLabels: plan.steps.map((s) => s.label),
        skippedByFlag: plan.skippedByFlag,
        context: config.statusContext
      },
      d.tail,
      d.log
    );
  } catch (err) {
    d.error(`[chreode] ${message(err)}`);
    return 1;
  }
  return 0;
}
```

```ts
import { tmpdir } from 'node:os';

import type { ResolvedConfig } from '../config/types.js';
import { isRecord } from '../config/validate.js';
import { defaultExec, type Exec } from '../run/exec.js';
import { repoInfo, type RepoInfo } from './status.js';

export const DEFAULT_BRANCH_PROTECTION: Record<string, unknown> = {
  enforce_admins: true,
  required_pull_request_reviews: {
    dismiss_stale_reviews: true,
    require_code_owner_reviews: false,
    required_approving_review_count: 0
  },
  restrictions: null,
  allow_force_pushes: false,
  allow_deletions: false,
  required_linear_history: true,
  required_conversation_resolution: false
};

export const DEFAULT_REPO_SETTINGS: Record<string, unknown> = {
  allow_squash_merge: true,
  allow_merge_commit: false,
  allow_rebase_merge: false,
  squash_merge_commit_title: 'PR_TITLE',
  squash_merge_commit_message: 'PR_BODY',
  delete_branch_on_merge: true
};

/** Defaults shallow-merged with config.protection; the status context is always required. */
export function protectionPayloads(config: ResolvedConfig): {
  branch: Record<string, unknown>;
  repo: Record<string, unknown>;
} {
  const override = config.protection.branch ?? {};
  const checks = isRecord(override.required_status_checks) ? override.required_status_checks : {};
  const extra = Array.isArray(checks.contexts)
    ? checks.contexts.filter((c): c is string => typeof c === 'string')
    : [];
  return {
    branch: {
      ...DEFAULT_BRANCH_PROTECTION,
      ...override,
      required_status_checks: {
        strict: true,
        ...checks,
        contexts: [...new Set([config.statusContext, ...extra])]
      }
    },
    repo: { ...DEFAULT_REPO_SETTINGS, ...(config.protection.repo ?? {}) }
  };
}

export interface ProtectDeps {
  exec: Exec;
  log: (m: string) => void;
  repo: () => RepoInfo;
}

/** Idempotently require the signoff status on the base branch and set squash-only merges. */
export function runProtect(
  config: ResolvedConfig,
  opts: { dryRun: boolean; repo: RepoInfo | null },
  overrides: Partial<ProtectDeps> = {}
): number {
  const d: ProtectDeps = {
    exec: defaultExec,
    log: (m) => console.log(m),
    repo: () => repoInfo(defaultExec),
    ...overrides
  };
  let repo = opts.repo;
  if (repo === null) {
    try {
      repo = d.repo();
    } catch (err) {
      if (!opts.dryRun) throw err;
      d.log('[chreode] gh repo view failed; showing payloads for <owner>/<repo>');
      repo = { owner: '<owner>', name: '<repo>' };
    }
  }
  const { branch, repo: settings } = protectionPayloads(config);
  const apply = (method: 'PUT' | 'PATCH', path: string, body: unknown) => {
    if (opts.dryRun) {
      d.log(`[dry-run] ${method} ${path}\n${JSON.stringify(body, null, 2)}`);
      return;
    }
    const dir = mkdtempSync(join(tmpdir(), 'chreode-protect-'));
    const file = join(dir, 'payload.json');
    writeFileSync(file, JSON.stringify(body));
    try {
      d.exec('gh', ['api', '-X', method, path, '--input', file]);
    } finally {
      rmSync(dir, { recursive: true, force: true });
    }
  };
  const target = `${repo.owner}/${repo.name}`;
  d.log(`[chreode] protecting ${target} ${config.baseBranch} (dry-run=${opts.dryRun})`);
  apply('PUT', `repos/${target}/branches/${config.baseBranch}/protection`, branch);
  apply('PATCH', `repos/${target}`, settings);
  d.log(`[chreode] ${config.baseBranch} now requires ${config.statusContext}`);
  return 0;
}
```

```ts
#!/usr/bin/env node
import { readFileSync, realpathSync } from 'node:fs';
import path from 'node:path';
import { pathToFileURL } from 'node:url';
import { Command } from 'commander';
import { CONFIG_FILE, loadConfig } from './config/load.js';
import type { ResolvedConfig } from './config/types.js';
import { parseRepo } from './github/status.js';
import { runProtect } from './github/protect.js';
import { defaultExec } from './run/exec.js';
import { runSignoff, type SignoffOptions } from './signoff/run.js';

export interface SignoffFlags {
  full?: boolean;
  dryRun?: boolean;
  merge?: boolean;
  push?: boolean;
  allowStderr?: boolean;
  base?: string;
  skip?: string[];
  config?: string;
}

export interface ProtectFlags {
  dryRun?: boolean;
  repo?: string;
  config?: string;
}

/** Each flag also has an env form, for harnesses that forbid flags after `--`. */
export function resolveSignoffOptions(flags: SignoffFlags, env: NodeJS.ProcessEnv): SignoffOptions {
  const on = (key: string) => env[key] === '1';
  return {
    full: flags.full === true || on('CHREODE_FULL'),
    dryRun: flags.dryRun === true,
    noMerge: flags.merge === false || on('CHREODE_NO_MERGE'),
    noPush: flags.push === false || on('CHREODE_NO_PUSH'),
    allowStderr: flags.allowStderr === true || on('CHREODE_ALLOW_STDERR'),
    base: flags.base ?? null,
    skip: flags.skip ?? []
  };
}

function readVersion(): string {
  const pkg = JSON.parse(readFileSync(new URL('../package.json', import.meta.url), 'utf8')) as {
    version: string;
  };
  return pkg.version;
}

const collect = (value: string, previous: string[]): string[] => [...previous, value];

export function buildProgram(
  actions: {
    signoff: (flags: SignoffFlags) => Promise<number>;
    protect: (flags: ProtectFlags) => Promise<number>;
  },
  setExit: (code: number) => void
): Command {
  const program = new Command('chreode')
    .description('A deterministic, selective, unavoidable local-CI gate')
    .version(readVersion());

  program
    .command('signoff')
    .description('merge the base branch, run the steps the changes need, push, post the status')
    .option('--full', 'ignore the incremental base and run every step (env CHREODE_FULL=1)')
    .option('--dry-run', 'print the plan and stop')
    .option('--no-merge', 'do not merge origin/<baseBranch> first (env CHREODE_NO_MERGE=1)')
    .option('--no-push', 'do not push; the commit must already be on origin (env CHREODE_NO_PUSH=1)')
    .option('--allow-stderr', 'downgrade policed stderr to a warning (env CHREODE_ALLOW_STDERR=1)')
    .option('--base <ref>', 'diff from this ref instead of the last signoff')
    .option('--skip <label>', 'skip a planned step; repeatable; named in the status', collect, [])
    .option('--config <path>', `config file (default: <repo root>/${CONFIG_FILE})`)
    .action(async (flags: SignoffFlags) => setExit(await actions.signoff(flags)));

  program
    .command('protect')
    .description('require the signoff status on the base branch (idempotent)')
    .option('--dry-run', 'print the payloads without applying them')
    .option('--repo <owner/name>', 'target repository (default: gh repo view)')
    .option('--config <path>', `config file (default: <repo root>/${CONFIG_FILE})`)
    .action(async (flags: ProtectFlags) => setExit(await actions.protect(flags)));

  return program;
}

/** Steps and git commands run from the repo root, whatever directory chreode was started in. */
async function loadFromRepo(configFlag: string | undefined): Promise<ResolvedConfig> {
  const explicit = configFlag ? path.resolve(configFlag) : null;
  const root = defaultExec('git', ['rev-parse', '--show-toplevel']).trim();
  process.chdir(root);
  return loadConfig(explicit ?? path.join(root, CONFIG_FILE));
}

export async function main(
  argv: string[] = process.argv,
  env: NodeJS.ProcessEnv = process.env
): Promise<number> {
  let code = 0;
  const program = buildProgram(
    {
      signoff: async (flags) =>
        runSignoff(await loadFromRepo(flags.config), resolveSignoffOptions(flags, env)),
      protect: async (flags) =>
        runProtect(await loadFromRepo(flags.config), {
          dryRun: flags.dryRun === true,
          repo: flags.repo ? parseRepo(flags.repo) : null
        })
    },
    (c) => {
      code = c;
    }
  );
  try {
    await program.parseAsync(argv);
  } catch (err) {
    console.error(`[chreode] ${err instanceof Error ? err.message : String(err)}`);
    return 1;
  }
  return code;
}

/** npm installs the bin as a symlink, so compare real paths, not the invoked path. */
export function isInvokedDirectly(moduleUrl: string, argv1: string | undefined): boolean {
  if (!argv1) return false;
  try {
    return moduleUrl === pathToFileURL(realpathSync(argv1)).href;
  } catch {
    return false;
  }
}

if (isInvokedDirectly(import.meta.url, process.argv[1])) {
  main().then(
    (code) => {
      process.exitCode = code;
    },
    (err: unknown) => {
      console.error(err);
      process.exitCode = 1;
    }
  );
}
```

```ts
  git(cwd, 'add', '-A');
  git(cwd, 'commit', '-q', '-m', message);
  return git(cwd, 'rev-parse', 'HEAD');
}

function setup(): Sandbox {
  const dir = mkdtempSync(join(tmpdir(), 'chreode-it-'));
  const origin = join(dir, 'origin.git');
  const work = join(dir, 'work');
  const bin = join(dir, 'bin');
  execFileSync('git', ['init', '-q', '--bare', '-b', 'main', origin], { env: cleanEnv() });
  mkdirSync(work);
  execFileSync('git', ['init', '-q', '-b', 'main'], { cwd: work, env: cleanEnv() });
  initRepo(work);
  git(work, 'remote', 'add', 'origin', origin);
  write(work, 'chreode.config.ts', CONFIG);
  write(work, 'src/a.ts', 'export const a = 1;\n');
  write(work, 'docs/guide.md', '# Guide\n');
  git(work, 'add', '-A');
  git(work, 'commit', '-q', '-m', 'init');
  git(work, 'push', '-q', '-u', 'origin', 'main');
  git(work, 'checkout', '-q', '-b', 'feature');
  mkdirSync(bin);
  writeFileSync(join(bin, 'gh'), GH_SHIM);
  chmodSync(join(bin, 'gh'), 0o755);
  const ranLog = join(dir, 'ran.log');
  const ghLog = join(dir, 'gh.log');
  return {
    dir,
    work,
    ranLog,
    ghLog,
    env: {
      ...cleanEnv(),
      PATH: `${bin}:${process.env.PATH ?? ''}`,
      RAN_LOG: ranLog,
      GH_LOG: ghLog,
      CHREODE_LOCK_PATH: join(dir, 'signoff.lock')
    }
  };
}

function signoff(sb: Sandbox, args: string[] = [], extraEnv: NodeJS.ProcessEnv = {}) {
  const r = spawnSync(TSX, [CLI, 'signoff', ...args], {
    cwd: sb.work,
    env: { ...sb.env, ...extraEnv },
    encoding: 'utf8'
  });
  return { status: r.status, out: `${r.stdout}${r.stderr}` };
}

const readLines = (file: string) =>
  existsSync(file) ? readFileSync(file, 'utf8').split('\n').filter(Boolean) : [];
const ran = (sb: Sandbox) => readLines(sb.ranLog);
const clearRan = (sb: Sandbox) => writeFileSync(sb.ranLog, '');
const statusPosts = (sb: Sandbox) =>
  readLines(sb.ghLog).filter((l) => l.startsWith('api -X POST repos/acme/widget/statuses/'));
const remoteFeature = (sb: Sandbox) => git(sb.work, 'ls-remote', 'origin', 'refs/heads/feature');

function note(sb: Sandbox, sha: string): string | null {
  try {
    return git(sb.work, 'notes', '--ref=chreode', 'show', sha);
  } catch {
    return null;
  }
}
```

````markdown
## Usage

### `chreode signoff`

1. **Preconditions**: clean tree, a branch (not detached, not the base branch), not behind its
   upstream, `gh auth status` ok, `git config user.email` set.
2. **Merge** `origin/<baseBranch>` (unless `--no-merge`). A conflict exits 1 and leaves the
   merge in progress. When the merge changed the branch, `afterMerge` runs.
3. **Base**: `--base`, else the nearest commit on the branch carrying a `refs/notes/chreode`
   note (the last successful signoff), else the merge-base with `origin/<baseBranch>`.
4. **Plan**: changed paths (both sides of renames, deletions included) → triggers (first
   matching rule; a path no rule matches fires every trigger) → steps (`when`, `if`,
   `--skip`, `supersededBy`). The plan and every skipped step's reason are printed.
5. **Run** the steps in order under one machine-wide lock shared by every chreode repo on the
   machine. Each step runs in its own process group with a hard timeout; policed steps fail
   on unexpected stderr. Children see `CHREODE_SIGNOFF=1`.
6. **Tail**: refuse if the steps changed the checkout; push; post `<statusContext>` = success
   naming the signer and any `--skip`'d steps; write the note.

| Flag               | Env                      | Effect                                           |
| ------------------ | ------------------------ | ------------------------------------------------ |
| `--full`           | `CHREODE_FULL=1`         | Ignore the incremental base; run every step      |
| `--dry-run`        |                          | Print the plan and stop                          |
| `--no-merge`       | `CHREODE_NO_MERGE=1`     | Do not merge `origin/<baseBranch>` first         |
| `--no-push`        | `CHREODE_NO_PUSH=1`      | Do not push (the commit must already be on origin) |
| `--allow-stderr`   | `CHREODE_ALLOW_STDERR=1` | Downgrade policed stderr to a warning            |
| `--base <ref>`     |                          | Diff from this ref                               |
| `--skip <label>`   |                          | Skip a planned step (repeatable; named in the status) |
| `--config <path>`  |                          | Config file (default `<repo root>/chreode.config.ts`) |

Exit codes: `0` signed off, already signed off, or dry run; `1` anything else.

The lock lives at `$TMPDIR/chreode-signoff.lock`. A waiter logs once and polls for up to an
hour; a lock whose holder died goes stale after 30 s and is stolen. `CHREODE_LOCK_PATH`
overrides the path (for test isolation only).

### `chreode protect`

`PUT`s branch protection on `<baseBranch>` requiring `<statusContext>` (strict), with admins
enforced, linear history, PRs required (0 approvals, stale reviews dismissed), and `PATCH`es
the repo to squash-only merges that delete head branches. Override either payload under
`protection` in the config. `--repo owner/name` targets another repo; `--dry-run` prints the
payloads.

## Config reference

```ts
import { defineConfig } from '@mindlace/chreode';

export default defineConfig({
  baseBranch: 'main', // default
  statusContext: 'chreode/signoff', // default
  rules: [
    { match: ['docs/**', '**/*.md'], triggers: ['format'] },
    { match: 'src/**', triggers: ['lint', 'check', 'unit', 'e2e'] },
    { match: 'generated/**', triggers: [] } // matched, nothing to run
  ],
  steps: [
    { label: 'format', run: 'npx prettier --check .', when: ['format'], supersededBy: ['lint'] },
    { label: 'lint', run: 'npm run lint', when: ['lint'] },
    { label: 'check', run: 'npm run check', when: ['check'] },
    { label: 'test:unit', run: 'npm run test:unit', when: ['unit'], policeStderr: true },
    {
      label: 'test:e2e',
      run: 'npm run test:e2e',
      when: ['e2e'],
      policeStderr: true,
      timeoutMs: 15 * 60_000
    }
  ],
  afterMerge: 'npm install',
  stderrAllowlist: [{ pattern: /^\[WebServer\] /, reason: 'Playwright echoes the preview server' }]
});
```

**Rules** are tried in order; the first whose `match` (a [picomatch](https://github.com/micromatch/picomatch)
glob, dotfiles included, or a RegExp, or an array of them) matches a changed path decides its
triggers. A path no rule matches fires every trigger: rules can only make runs smaller, so a
forgotten rule costs time, never coverage. Triggers are free-form strings.

**Steps** run in config order.

| Field          | Type                          | Meaning                                                              |
| -------------- | ----------------------------- | -------------------------------------------------------------------- |
| `label`        | string                        | Unique, no whitespace. Used by `--skip`, the note and the status.    |
| `run`          | `string \| (ctx) => string`   | Shell command. `ctx` is `{ base, head, paths, triggers, isWorktree }`. |
| `when`         | string[]                      | Planned if any listed trigger fired.                                 |
| `if`           | `(ctx) => boolean`            | Extra predicate, e.g. only in a worktree.                            |
| `supersededBy` | string[]                      | Dropped when any listed step will also run.                          |
| `policeStderr` | boolean                       | Fail a clean exit that wrote non-allowlisted stderr.                 |
| `timeoutMs`    | number                        | Hard ceiling; default 10 minutes.                                    |

**`afterMerge`** runs only when merging `origin/<baseBranch>` changed the branch.
**`stderrAllowlist`** entries need a `reason`: allowlisting noise is a reviewed decision.
Unknown keys, duplicate labels, and `supersededBy` naming a missing step are load errors.
````
