# chreode flakes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `@mindlace/chreode` v0.2.0 with flake telemetry (Playwright and vitest reporters writing `.chreode/flakes.jsonl`), a GitHub-issue flake ledger that runs as a built-in signoff phase and escalates at 3 occurrences, `chreode flake-report`, `chreode burn-in` with a `burnInStep()` helper, and a generic flake doctrine doc; then adopt it in sfhousing with local retries turned on.

**Architecture:** A new `src/flakes/` package holds the log (jsonl IO, repo-relative paths), the pure ledger (`processFlakeEvents`, GitHub calls injected), the `gh` adapter (over chreode's `Exec`), and the phase that reads the log, runs the ledger and clears or keeps the log. `src/reporters/` holds two thin reporters that only import runner *types*. `src/burn-in/` holds pure selection (changed paths → runner groups → commands), the runner, and the step helper. `signoff/run.ts` exports `CHREODE_HEAD`/`CHREODE_FLAKE_LOG` to steps and runs the flake phase after the steps, pass or fail, before the clean-tree check and the tail.

**Tech Stack:** As core (Node ≥ 22.12, TypeScript ~6.0 strict NodeNext, commander 15, picomatch 4, vitest 4, tsx for integration tests), plus dev-only `@playwright/test` + `playwright` ^1.62 (types and one non-browser smoke test). `playwright` and `vitest` become optional peerDependencies.

**Spec:** `docs/superpowers/specs/2026-10-11-2029-flakes-design.md` (read it before starting any task). The style reference for this plan is `docs/superpowers/plans/2026-10-11-1710-chreode-core.md`.

## Review Focus

1. **Worktrees have a `.git` *file*.** Both chreode and sfhousing are developed in git worktrees, where `<root>/.git` is a file pointing at the common dir. A repo-root finder that looks for a `.git` *directory* walks past the worktree root and yields paths like `.claude/worktrees/x/e2e/a.spec.ts`, which then never match the issue filed from the main checkout. Expect `file` to be relative to the worktree root. (Task 2 pins it.)
2. **Test titles carry shell metacharacters.** Titles like `` handles "quotes", `ticks` and $(subshells) `` go into `gh issue create --title/--body`. Expect them to reach GitHub verbatim and never be interpreted by a shell. (Task 6 pins it: argv only, no shell.)
3. **Renamed and deleted test files in burn-in.** A spec renamed on the branch must be burned in under its new name; a deleted spec must not be passed to a runner (which would fail with "no tests found"). Expect `base..head` renames to count as the new path only and deletions to be dropped. (Task 9 pins the git arguments; Task 12 pins real git behaviour.)
4. **GitHub fails halfway through a report.** One issue is filed, then the next comment hits an HTTP 502. Keeping the *whole* log would re-report the already-filed flake next run, which then finds its fresh issue and counts a second occurrence it never had, escalating early. Expect only the events not yet recorded to be kept. (Tasks 5 and 7 pin it.)
5. **Playwright error messages are ANSI-coloured.** `result.error.message` is full of `\x1b[31m`-style codes, which render as garbage in an issue body. Expect the first-attempt error to be ANSI-stripped before it is logged. (Tasks 2 and 3 pin it.)

## Spec deviations and resolved gaps

- **Escalation and the status description.** The spec says on escalation "the status description names the escalation". A failing chreode run posts no status at all (core design: failures post nothing), so the escalation is named in the run's error output, with every escalated issue URL, and no status is posted.
- **Partial `gh` failure keeps only unprocessed events** (Review Focus 4), a refinement of "log kept". The ledger throws a `LedgerError` carrying the partial result and the remaining (deduped) events; the phase rewrites the log with those.
- **`threshold: 1`** escalates on filing (count 1 ≥ 1). With the default 3 this never applies.
- **`chreode flake-report` without a `flakes` block** uses the defaults (it is an explicit request to report). **`chreode burn-in` without a `burnIn` block** exits 1 with a message (a `burnInStep` wired without runners is a config bug that must not pass silently).
- **Runner `ignore`** applies to that runner only: a file one runner ignores can still go to a later runner that matches it. "First runner wins" means the first runner that matches and does not ignore it.
- **Issue URLs**: the listing adds `url` to the spec's `--json number,title,labels` so escalations can print links; `gh issue create`'s printed URL supplies the new issue's number and URL.
- **Label creation**: before the first `gh issue create` in a run, `gh label list --limit 1000 --json name` is checked and `gh label create flake --description … --color D93F0B` runs if missing.
- **`CHREODE_HEAD`/`CHREODE_FLAKE_LOG`** go to steps only (not `afterMerge`, which runs before HEAD is final).
- **Ctrl-C mid-step** still runs the flake phase (the step was interrupted, not the run's bookkeeping); a second Ctrl-C kills chreode as before.
- **Repo root for reporter paths** is found by walking up from the test file for a `.git` entry (file or directory), falling back to `process.cwd()`; no `git` subprocess per test.
- **sfhousing Playwright retries become `1` everywhere** (CI was already 1; local was 0). Burn-in runners: `e2e` (chromium only, ignoring `helpers/`, `fixtures/`, `bench/`, `*.perf.spec.ts`, which are not in the chromium project), `client` before `server` (the server globs also match `*.svelte.spec.ts`). The burn-in step gets a 20-minute timeout (each Playwright invocation rebuilds the app).
- Version bump to `0.2.0` (new features, pre-1.0 minor).

function validateFlakes(raw: unknown, problems: string[]): ResolvedFlakes | null {
  if (raw === undefined) return null;
  if (!isRecord(raw)) {
    problems.push('config.flakes: must be an object ({} turns flake tracking on with the defaults)');
    return null;
  }
  unknownKeys(raw, FLAKES_KEYS, 'flakes', problems);
  if (raw.threshold !== undefined && !isPositiveInteger(raw.threshold)) {
    problems.push('flakes.threshold: must be a positive integer');
  }
  for (const key of ['snoozeLabel', 'playbookUrl'] as const) {
    if (raw[key] !== undefined && !isNonEmptyString(raw[key])) {
      problems.push(`flakes.${key}: must be a non-empty string`);
    }
  }
  return resolveFlakes(raw as FlakesConfig);
}

function validateBurnIn(raw: unknown, problems: string[]): ResolvedBurnIn | null {
  if (raw === undefined) return null;
  if (!isRecord(raw)) {
    problems.push('config.burnIn: must be an object');
    return null;
  }
  unknownKeys(raw, BURN_IN_KEYS, 'burnIn', problems);
  for (const key of ['repeats', 'maxFiles'] as const) {
    if (raw[key] !== undefined && !isPositiveInteger(raw[key])) {
      problems.push(`burnIn.${key}: must be a positive integer`);
    }
  }
  const runners = raw.runners;
  if (!Array.isArray(runners) || runners.length === 0) {
    problems.push('burnIn.runners: must be a non-empty array');
  } else {
    runners.forEach((runner: unknown, i) => {
      const where = `burnIn.runners[${i}]`;
      if (!isRecord(runner)) {
        problems.push(`${where}: must be an object`);
        return;
      }
      unknownKeys(runner, RUNNER_KEYS, where, problems);
      if (!isNonEmptyString(runner.name)) problems.push(`${where}.name: must be a non-empty string`);
      if (!isMatcherList(runner.match)) problems.push(`${where}.match: ${MATCHER_PROBLEM}`);
      if (runner.ignore !== undefined && !isMatcherList(runner.ignore)) {
        problems.push(`${where}.ignore: ${MATCHER_PROBLEM}`);
      }
      if (typeof runner.command !== 'function') {
        problems.push(`${where}.command: must be a function (files, repeats) => string | string[]`);
      }
    });
  }
  return {
    repeats: (raw.repeats as number | undefined) ?? DEFAULT_BURN_IN_REPEATS,
    maxFiles: (raw.maxFiles as number | undefined) ?? DEFAULT_BURN_IN_MAX_FILES,
    runners: Array.isArray(runners) ? (runners as BurnInRunner[]) : []
  };
}
```

import { appendFileSync, existsSync, mkdirSync, readFileSync, rmSync, writeFileSync } from 'node:fs';
import { dirname, join, relative, sep } from 'node:path';
import { stripAnsi } from '../run/stderr.js';

/** One retried-then-passed test, as a reporter saw it. */
export interface FlakeEvent {
  /** Issue-title bucket, e.g. 'e2e', 'unit', 'client'. */
  kind: string;
  runner: 'playwright' | 'vitest';
  /** Runner project name ('' if none). */
  project: string;
  /** Repo-relative, '/'-separated. */
  file: string;
  /** Describe chain joined with ' › '. */
  title: string;
  /** At most ERROR_LINE_CAP lines, ANSI-stripped. */
  firstAttemptError: string;
  /** Playwright trace of the failed attempt. */
  tracePath?: string;
  /** CHREODE_HEAD when run under signoff. */
  sha?: string;
  /** ISO timestamp. */
  at: string;
}

/** Repo-relative. Not under test-results/: Playwright wipes its outputDir at start and would
 *  delete events an earlier vitest step wrote. */
export const FLAKE_LOG_FILE = '.chreode/flakes.jsonl';
export const ERROR_LINE_CAP = 40;

export function flakeLogPath(
  env: NodeJS.ProcessEnv = process.env,
  cwd: string = process.cwd()
): string {
  const fromEnv = env.CHREODE_FLAKE_LOG;
  return fromEnv !== undefined && fromEnv !== '' ? fromEnv : join(cwd, FLAKE_LOG_FILE);
}

/** jsonl, append-only: sequential writer processes in one run never clobber each other. */
export function appendFlakeEvent(event: FlakeEvent, logPath: string): void {
  mkdirSync(dirname(logPath), { recursive: true });
  appendFileSync(logPath, `${JSON.stringify(event)}\n`);
}

const REQUIRED = ['kind', 'runner', 'project', 'file', 'title', 'firstAttemptError', 'at'] as const;

function isFlakeEvent(v: unknown): v is FlakeEvent {
  if (typeof v !== 'object' || v === null) return false;
  const record = v as Record<string, unknown>;
  return REQUIRED.every((key) => typeof record[key] === 'string');
}

export function readFlakeEvents(logPath: string): FlakeEvent[] {
  if (!existsSync(logPath)) return [];
  const events: FlakeEvent[] = [];
  for (const line of readFileSync(logPath, 'utf8').split('\n')) {
    if (line.trim() === '') continue;
    try {
      const parsed: unknown = JSON.parse(line);
      if (isFlakeEvent(parsed)) events.push(parsed);
    } catch {
      // An interrupted write: skip it rather than fail the report.
    }
  }
  return events;
}

export function clearFlakeLog(logPath: string): void {
  rmSync(logPath, { force: true });
}

export function writeFlakeEvents(logPath: string, events: readonly FlakeEvent[]): void {
  if (events.length === 0) {
    clearFlakeLog(logPath);
    return;
  }
  mkdirSync(dirname(logPath), { recursive: true });
  writeFileSync(logPath, events.map((e) => `${JSON.stringify(e)}\n`).join(''));
}

export function flakeKey(event: FlakeEvent): string {
  return `${event.kind}/${event.file}/${event.title}`;
}

/** One report per test per run: the same flake seen in two projects counts once. */
export function dedupeEvents(events: readonly FlakeEvent[]): FlakeEvent[] {
  const seen = new Set<string>();
  return events.filter((e) => {
    const key = flakeKey(e);
    if (seen.has(key)) return false;
    seen.add(key);
    return true;
  });
}

export function truncateError(message: string | undefined): string {
  if (message === undefined || message === '') return '(first attempt error unavailable)';
  return stripAnsi(message).split('\n').slice(0, ERROR_LINE_CAP).join('\n');
}

/** The nearest ancestor holding `.git`: a directory in a checkout, a file in a worktree. */
export function findRepoRoot(
  start: string,
  exists: (path: string) => boolean = existsSync
): string | null {
  let dir = start;
  for (;;) {
    if (exists(join(dir, '.git'))) return dir;
    const parent = dirname(dir);
    if (parent === dir) return null;
    dir = parent;
  }
}

/** Relative to the git root found from the file itself, so a runner started in a subpackage
 *  still yields repo paths; '/'-separated. */
export function repoRelative(file: string, cwd: string = process.cwd()): string {
  const root = findRepoRoot(dirname(file)) ?? cwd;
  return relative(root, file).split(sep).join('/');
}
```

import { appendFlakeEvent, flakeLogPath, type FlakeEvent } from '../flakes/log.js';

export interface FlakeReporterOptions {
  /** Issue-title bucket: fixed, or derived from the runner project name. */
  kind?: string | ((project: string) => string);
  /** Record only these runner projects (default: all). */
  projects?: string[];
  /** Where events go (default: appended to the flake log). A seam for tests. */
  append?: (event: FlakeEvent) => void;
}

export function resolveKind(
  kind: FlakeReporterOptions['kind'],
  project: string,
  fallback: string
): string {
  if (typeof kind === 'function') return kind(project);
  return kind ?? fallback;
}

export function wants(projects: readonly string[] | undefined, project: string): boolean {
  return projects === undefined || projects.includes(project);
}

/** The sha under test when running under signoff. */
export function headSha(env: NodeJS.ProcessEnv = process.env): { sha?: string } {
  const sha = env.CHREODE_HEAD;
  return sha ? { sha } : {};
}

/** Resolved at write time, so CHREODE_FLAKE_LOG set by signoff is honoured. */
export function defaultAppend(event: FlakeEvent): void {
  appendFlakeEvent(event, flakeLogPath());
}

import type { Reporter, TestCase, TestResult } from 'playwright/types/testReporter';
import { repoRelative, truncateError, type FlakeEvent } from '../flakes/log.js';
import {
  defaultAppend,
  headSha,
  resolveKind,
  wants,
  type FlakeReporterOptions
} from './options.js';

/**
 * Records every test that failed (or timed out) and then passed on a retry. Playwright loads
 * reporters by module specifier, hence the default export. Imports Playwright's types only.
 */
export default class PlaywrightFlakeReporter implements Reporter {
  private readonly options: FlakeReporterOptions;
  private readonly append: (event: FlakeEvent) => void;
  /** The first failed attempt of each test that has not passed yet. */
  private readonly failed = new Map<string, TestResult>();

  constructor(options: FlakeReporterOptions = {}) {
    this.options = options;
    this.append = options.append ?? defaultAppend;
  }

  onTestEnd(test: TestCase, result: TestResult): void {
    if (result.status === 'failed' || result.status === 'timedOut') {
      if (!this.failed.has(test.id)) this.failed.set(test.id, result);
      return;
    }
    const first = this.failed.get(test.id);
    if (result.status !== 'passed' || result.retry === 0 || first === undefined) return;
    this.failed.delete(test.id);
    // ['', project, file, ...describes, title]
    const titlePath = test.titlePath();
    const project = titlePath[1] ?? '';
    if (!wants(this.options.projects, project)) return;
    const trace = first.attachments.find((a) => a.name === 'trace')?.path;
    this.append({
      kind: resolveKind(this.options.kind, project, 'e2e'),
      runner: 'playwright',
      project,
      file: repoRelative(test.location.file),
      title: titlePath.slice(3).join(' › '),
      firstAttemptError: truncateError(first.error?.message),
      ...(trace ? { tracePath: trace } : {}),
      ...headSha(),
      at: new Date().toISOString()
    });
  }

  printsToStdio(): boolean {
    return false;
  }
}

/** The parent's env minus chreode's and vitest's own variables, so the nested runner behaves

function childEnv(extra: NodeJS.ProcessEnv): NodeJS.ProcessEnv {
  const env: NodeJS.ProcessEnv = {};
  for (const [key, value] of Object.entries(process.env)) {
    if (!key.startsWith('CHREODE_') && !key.startsWith('VITEST')) env[key] = value;

  return { ...env, ...extra };

```ts
import type { Reporter, TestCase, TestModule, TestSuite } from 'vitest/node';
import { repoRelative, truncateError, type FlakeEvent } from '../flakes/log.js';
import {
  defaultAppend,
  headSha,
  resolveKind,
  wants,
  type FlakeReporterOptions
} from './options.js';

interface Where {
  project: string;
  file: string;
}

/**
 * Records every test that passed after at least one retry. vitest reporters are a root-level
 * option, so instantiate this in the root config's `reporters`; it sees every project and
 * filters with `projects`. Imports vitest's types only.
 */
export class VitestFlakeReporter implements Reporter {
  private readonly options: FlakeReporterOptions;
  private readonly append: (event: FlakeEvent) => void;

  constructor(options: FlakeReporterOptions = {}) {
    this.options = options;
    this.append = options.append ?? defaultAppend;
  }

  onTestRunEnd(testModules: ReadonlyArray<TestModule>): void {
    for (const testModule of testModules) {
      const project = testModule.project.name;
      if (!wants(this.options.projects, project)) continue;
      const where = { project, file: repoRelative(testModule.moduleId) };
      this.walk(testModule.children.array(), [], where);
    }
  }

  private walk(
    entities: ReadonlyArray<TestSuite | TestCase>,
    titles: string[],
    where: Where
  ): void {
    for (const entity of entities) {
      if (entity.type === 'suite') {
        this.walk(entity.children.array(), [...titles, entity.name], where);
        continue;
      }
      const result = entity.result();
      if (result.state !== 'passed' || (entity.diagnostic()?.retryCount ?? 0) === 0) continue;
      this.append({
        kind: resolveKind(this.options.kind, where.project, where.project || 'unit'),
        runner: 'vitest',
        project: where.project,
        file: where.file,
        title: [...titles, entity.name].join(' › '),
        // A test that passed on retry still reports the errors of its failed attempts.
        firstAttemptError: truncateError(result.errors?.[0]?.message),
        ...headSha(),
        at: new Date().toISOString()
      });
    }
  }
}

export default VitestFlakeReporter;
```

```ts
import type { ResolvedFlakes } from '../config/types.js';
import { dedupeEvents, type FlakeEvent } from './log.js';

export const FLAKE_LABEL = 'flake';
export const OCCURRENCE_MARKER = '<!-- chreode:flake-occurrence -->';
export const ISSUE_TITLE_MAX = 256;

export interface RunContext {
  branch: string;
  sha: string;
}

export interface FlakeIssue {
  number: number;
  title: string;
  url: string;
  labels: string[];
}

/** The GitHub side, injected: see gh.ts for the real one. */
export interface FlakeLedgerDeps {
  /** Open issues labelled FLAKE_LABEL. */
  listOpenFlakeIssues(): FlakeIssue[];
  /** Comments on the issue that carry OCCURRENCE_MARKER. */
  countOccurrenceComments(issue: number): number;
  /** Creates an issue labelled FLAKE_LABEL. */
  createIssue(title: string, body: string): FlakeIssue;
  commentIssue(issue: number, body: string): void;
}

export interface LedgerEntry {
  number: number;
  title: string;
  url: string;
  /** Occurrences so far: 1 (the issue) + marker comments. */
  count: number;
}

export interface LedgerResult {
  filed: LedgerEntry[];
  bumped: LedgerEntry[];
  escalations: LedgerEntry[];
}

export function firstLine(err: unknown): string {
  return (err instanceof Error ? err.message : String(err)).split('\n')[0] ?? '';
}

/** A GitHub call failed partway: `partial` was recorded, `remaining` was not. */
export class LedgerError extends Error {
  constructor(
    readonly partial: LedgerResult,
    readonly remaining: FlakeEvent[],
    cause: unknown
  ) {
    super(firstLine(cause), { cause });
    this.name = 'LedgerError';
  }
}

export function issueTitle(event: FlakeEvent): string {
  return `flake(${event.kind}): ${event.file} › ${event.title}`.slice(0, ISSUE_TITLE_MAX);
}

function details(event: FlakeEvent, ctx: RunContext): string {
  const where = event.project === '' ? event.runner : `${event.runner}, project ${event.project}`;
  return [
    `- **Test:** \`${event.file}\` › ${event.title} (${where})`,
    `- **Observed:** ${event.at} on \`${ctx.branch}\` @ ${event.sha ?? ctx.sha}`,
    ...(event.tracePath ? [`- **First-attempt trace:** \`${event.tracePath}\``] : []),
    '',
    '**First-attempt error:**',
    '```',
    event.firstAttemptError,
    '```'
  ].join('\n');
}

export function issueBody(event: FlakeEvent, ctx: RunContext, config: ResolvedFlakes): string {
  return [
    'Filed by chreode flake tracking: this test failed, then passed on retry.',
    '',
    details(event, ctx),
    '',
    `A flake is a bug, not noise. Diagnose it with the playbook: ${config.playbookUrl}`,
    `At ${config.threshold} recorded occurrences it fails signoff until fixed; label this issue`,
    `\`${config.snoozeLabel}\` to defer that deliberately.`
  ].join('\n');
}

export function occurrenceBody(event: FlakeEvent, ctx: RunContext): string {
  return [OCCURRENCE_MARKER, '', 'Flaked again.', '', details(event, ctx)].join('\n');
}

/**
 * One open issue per flaking test (exact title match); each later sighting adds a marker
 * comment. An issue at `threshold` occurrences without the snooze label is an escalation.
 * Any GitHub failure throws LedgerError naming what was and was not recorded.
 */
export function processFlakeEvents(
  events: readonly FlakeEvent[],
  ctx: RunContext,
  config: ResolvedFlakes,
  deps: FlakeLedgerDeps
): LedgerResult {
  const result: LedgerResult = { filed: [], bumped: [], escalations: [] };
  const unique = dedupeEvents(events);
  if (unique.length === 0) return result;
  let open: FlakeIssue[];
  try {
    open = [...deps.listOpenFlakeIssues()];
  } catch (err) {
    throw new LedgerError(result, unique, err);
  }
  for (const [i, event] of unique.entries()) {
    try {
      const title = issueTitle(event);
      const existing = open.find((candidate) => candidate.title === title);
      let entry: LedgerEntry;
      let labels: string[];
      if (existing === undefined) {
        const created = deps.createIssue(title, issueBody(event, ctx, config));
        // A later event whose title truncates to the same string bumps this issue.
        open.push(created);
        entry = { number: created.number, title, url: created.url, count: 1 };
        labels = created.labels;
        result.filed.push(entry);
      } else {
        const prior = deps.countOccurrenceComments(existing.number);
        deps.commentIssue(existing.number, occurrenceBody(event, ctx));
        entry = { number: existing.number, title, url: existing.url, count: prior + 2 };
        labels = existing.labels;
        result.bumped.push(entry);
      }
      if (entry.count >= config.threshold && !labels.includes(config.snoozeLabel)) {
        result.escalations.push(entry);
      }
    } catch (err) {
      throw new LedgerError(result, unique.slice(i), err);
    }
  }
  return result;
}
```

Note: when an issue created this run is bumped again by a colliding title, `prior` comes from GitHub (0) so its count is 2; that is correct (two sightings).

import { defaultExec, lines, type Exec } from '../run/exec.js';
import { FLAKE_LABEL, OCCURRENCE_MARKER, type FlakeIssue, type FlakeLedgerDeps } from './ledger.js';

const LABEL_DESCRIPTION = 'A test that failed, then passed on retry (chreode)';
const LABEL_COLOR = 'D93F0B';

interface RawIssue {
  number: number;
  title: string;
  url: string;
  labels: { name: string }[];
}

/** The ledger's GitHub side over `gh`. Every call is argv (no shell), so test titles and
 *  error text reach GitHub verbatim. */
export function ghLedgerDeps(exec: Exec = defaultExec): FlakeLedgerDeps {
  let labelReady = false;
  const ensureLabel = () => {
    if (labelReady) return;
    const labels = JSON.parse(exec('gh', ['label', 'list', '--limit', '1000', '--json', 'name'])) as {
      name: string;
    }[];
    if (!labels.some((l) => l.name === FLAKE_LABEL)) {
      exec('gh', [
        'label',
        'create',
        FLAKE_LABEL,
        '--description',
        LABEL_DESCRIPTION,
        '--color',
        LABEL_COLOR
      ]);
    }
    labelReady = true;
  };
  return {
    listOpenFlakeIssues(): FlakeIssue[] {
      // A label filter, not a title search: it does not depend on search-index lag.
      const raw = JSON.parse(
        exec('gh', [
          'issue',
          'list',
          '--label',
          FLAKE_LABEL,
          '--state',
          'open',
          '--limit',
          '1000',
          '--json',
          'number,title,labels,url'
        ])
      ) as RawIssue[];
      return raw.map((i) => ({
        number: i.number,
        title: i.title,
        url: i.url,
        labels: i.labels.map((l) => l.name)
      }));
    },
    countOccurrenceComments(issue: number): number {
      const raw = JSON.parse(exec('gh', ['issue', 'view', String(issue), '--json', 'comments'])) as {
        comments: { body: string }[];
      };
      return raw.comments.filter((c) => c.body.includes(OCCURRENCE_MARKER)).length;
    },
    createIssue(title: string, body: string): FlakeIssue {
      ensureLabel();
      const out = exec('gh', ['issue', 'create', '--title', title, '--body', body, '--label', FLAKE_LABEL]);
      const url = lines(out).at(-1) ?? '';
      const m = /\/issues\/(\d+)$/.exec(url);
      if (!m) throw new Error(`gh issue create printed no issue URL: ${out.trim()}`);
      return { number: Number(m[1]), title, url, labels: [FLAKE_LABEL] };
    },
    commentIssue(issue: number, body: string): void {
      exec('gh', ['issue', 'comment', String(issue), '--body', body]);
    }
  };
}
```

import type { ResolvedFlakes } from '../config/types.js';
import {
  LedgerError,
  processFlakeEvents,
  type FlakeLedgerDeps,
  type LedgerEntry,
  type LedgerResult,
  type RunContext
} from './ledger.js';
import { clearFlakeLog, readFlakeEvents, writeFlakeEvents } from './log.js';

export interface FlakePhaseInput {
  logPath: string;
  ctx: RunContext;
  config: ResolvedFlakes;
  ledger: FlakeLedgerDeps;
  log: (m: string) => void;
  warn: (m: string) => void;
}

export type FlakePhaseOutcome =
  | { kind: 'none' }
  | { kind: 'reported'; result: LedgerResult }
  | { kind: 'gh-error'; message: string; partial: LedgerResult };

function printResult(result: LedgerResult, log: (m: string) => void): void {
  for (const f of result.filed) log(`[chreode] flake filed: ${f.url} ${f.title}`);
  for (const b of result.bumped) {
    log(`[chreode] flake seen again (${b.count} occurrences): ${b.url} ${b.title}`);
  }
}

/**
 * Report the logged flakes to the ledger. Recorded events leave the log; on a GitHub failure
 * the unrecorded ones stay for the next run (an outage must not block merging, and each event
 * keeps its own sha and time). Escalations are returned, not acted on: the caller decides.
 */
export function runFlakePhase(input: FlakePhaseInput): FlakePhaseOutcome {
  const events = readFlakeEvents(input.logPath);
  if (events.length === 0) return { kind: 'none' };
  input.log(`\n[chreode] flakes: ${events.length} retried-then-passed result(s) recorded`);
  let result: LedgerResult;
  try {
    result = processFlakeEvents(events, input.ctx, input.config, input.ledger);
  } catch (err) {
    if (!(err instanceof LedgerError)) throw err;
    printResult(err.partial, input.log);
    writeFlakeEvents(input.logPath, err.remaining);
    input.warn(
      `[chreode] flakes: a GitHub call failed (${err.message}); kept ` +
        `${err.remaining.length} event(s) in ${input.logPath} for the next run`
    );
    return { kind: 'gh-error', message: err.message, partial: err.partial };
  }
  clearFlakeLog(input.logPath);
  printResult(result, input.log);
  return { kind: 'reported', result };
}

export function escalationMessage(
  escalations: readonly LedgerEntry[],
  config: ResolvedFlakes
): string {
  return [
    `\n[chreode] FAILED: ${escalations.length} flake(s) reached ${config.threshold} occurrences:`,
    ...escalations.map((e) => `  ${e.url} (${e.count} occurrences) ${e.title}`),
    `[chreode] Fix each one (playbook: ${config.playbookUrl}), or label its issue`,
    `[chreode] ${config.snoozeLabel} to defer it deliberately.`
  ].join('\n');
}
```

function defaultDeps(

  return {

    warn: (m) => console.warn(m),
    error: (m) => console.error(m)
  };

function message(err: unknown): string {
  return err instanceof Error ? err.message : String(err);
}

/** Why the checkout no longer matches `head`, or null when it is clean and unmoved. */
function checkoutChange(head: string, exec: Exec): string | null {
  if (exec('git', ['status', '--porcelain']).trim() !== '') return 'the working tree is dirty';
  const now = exec('git', ['rev-parse', 'HEAD']).trim();
  return now !== head ? `HEAD moved to ${now}` : null;
}

export function printPlan(
  plan: Plan,
  where: { base: string; head: string; paths: readonly string[]; full: boolean },
  log: (m: string) => void
): void {
  log(`[chreode] base=${where.base} head=${where.head}${where.full ? ' (--full)' : ''}`);
  log(`[chreode] changed paths (${where.paths.length}):`);
  for (const p of where.paths) log(`  ${p}`);
  if (plan.unmatched.length > 0) {
    log(`[chreode] matched no rule, so every trigger fired: ${plan.unmatched.join(', ')}`);
  }
  log(`[chreode] triggers: ${plan.triggers.length > 0 ? plan.triggers.join(', ') : '(none)'}`);
  log(
    `[chreode] plan: ${plan.steps.length > 0 ? plan.steps.map((s) => s.label).join(', ') : '(no steps: a no-op signoff)'}`
  );
  for (const { label, reason } of plan.skipped) {
    log(`[chreode] skipping ${label} (${describeSkip(reason)})`);
  }
}

/**
 * `loadConfig` is called once up front and again after a merge that changed the branch, so
 * a merge that brings in a new chreode.config.ts is planned and run under that config.
 */
export async function runSignoff(
  loadConfig: () => Promise<ResolvedConfig>,
  opts: SignoffOptions,
  overrides: Partial<SignoffDeps> = {}
): Promise<number> {
  let config = await loadConfig();
  let d: SignoffDeps = { ...defaultDeps(config, opts), ...overrides };
  const baseBranch = config.baseBranch;

  // 1. Preconditions
  let pre: Preconditions;
  try {
    pre = checkPreconditions(baseBranch, d.exec, { flakes: config.flakes !== null });
  } catch (err) {
    if (err instanceof PreconditionError) {
      d.error(`[chreode] ${err.message}`);
      return 1;
    }
    throw err;
  }

  // 2. Merge
  const merge = mergeBaseBranch(baseBranch, { noMerge: opts.noMerge }, d.exec, d.warn);
  if (merge.kind === 'conflict') {
    d.error(
      `\n[chreode] merging origin/${baseBranch} hit a conflict. The merge is in progress.\n` +
        `Resolve it, run \`git commit --no-edit\`, then re-run signoff.\n` +
        `To bail out: \`git merge --abort\`.`
    );
    return 1;
  }
  if (merge.kind === 'failed') {
    d.error(`[chreode] merging origin/${baseBranch} failed: ${merge.message}`);
    return 1;
  }
  if (merge.kind === 'merged') {
    d.log(`[chreode] merged origin/${baseBranch} into ${pre.branch}`);
    if (config.afterMerge) {
      d.log(`[chreode] afterMerge: ${config.afterMerge}`);
      const before = d.exec('git', ['rev-parse', 'HEAD']).trim();
      try {
        d.run(config.afterMerge);
      } catch {
        d.error('[chreode] afterMerge failed');
        return 1;
      }
      const moved = checkoutChange(before, d.exec);
      if (moved) {
        d.error(
          `[chreode] afterMerge changed the checkout (${moved}); commit the change and re-run signoff.`
        );
        return 1;
      }
    }
    // The merge may have changed the config itself: plan under what is now checked out.
    try {
      config = await loadConfig();
    } catch (err) {
      d.error(
        `[chreode] the config merged in from origin/${baseBranch} failed to load: ${message(err)}\n` +
          `Fix it in a commit on this branch, then re-run signoff.`
      );
      return 1;
    }
    d = { ...defaultDeps(config, opts), ...overrides };
  }

  // 3. Resolve base
  const head = d.exec('git', ['rev-parse', 'HEAD']).trim();
  let base: BaseInfo['base'];
  let source: BaseInfo['source'] | 'flag';
  try {
    if (opts.base !== null) {
      base = resolveRef(opts.base, d.exec);
      source = 'flag';
    } else {
      ({ base, source } = resolveBase(baseBranch, d.exec));
    }
  } catch (err) {
    d.error(`[chreode] could not resolve the base: ${message(err)}`);
    return 1;
  }
  if (!opts.full && base === head) {
    d.log(
      source === 'note'
        ? `[chreode] already signed off at ${head}; nothing to do (--full re-runs everything)`
        : `[chreode] nothing to sign off: ${base} is HEAD`
    );
    return 0;
  }

  // 4. Plan
  const paths = committedPaths(base, head, d.exec);
  let plan: Plan;
  try {
    plan = planSignoff(config, {
      paths,
      full: opts.full,
      skip: opts.skip,
      base,
      head,
      isWorktree: isWorktree(d.exec)
    });
  } catch (err) {
    if (err instanceof PlanError) {
      d.error(`[chreode] ${err.message}`);
      return 1;
    }
    throw err;
  }
  printPlan(plan, { base, head, paths, full: opts.full }, d.log);
  if (opts.dryRun) {
    d.log('[chreode] --dry-run: stopping before the run');
    return 0;
  }

  // 5. Run. Steps learn the sha under test and where reporters record flakes.
  d = {
    ...defaultDeps(config, opts, { CHREODE_HEAD: head, CHREODE_FLAKE_LOG: d.flakeLog }),
    ...overrides
  };
  let allowedStderr: string[] = [];
  let stepsFailed = false;
  try {
    allowedStderr = await runSteps(plan.steps, d.lock, d.runStep);
  } catch (err) {
    if (!(err instanceof StepFailure)) d.error(`[chreode] ${message(err)}`);
    stepsFailed = true;
  }

  // 6. Flakes: after the steps, passed or failed, so a flake is charged to the run that saw
  //    it. Network, not machine load: the lock is already released.
  let escalated = false;
  if (config.flakes !== null) {
    const outcome = runFlakePhase({
      logPath: d.flakeLog,
      ctx: { branch: pre.branch, sha: head },
      config: config.flakes,
      ledger: d.ledger,
      log: d.log,
      warn: d.warn
    });
    if (outcome.kind === 'reported' && outcome.result.escalations.length > 0) {
      d.error(escalationMessage(outcome.result.escalations, config.flakes));
      escalated = true;
    }
  }
  if (stepsFailed || escalated) return 1;

  // What was tested must be exactly HEAD.
  const changed = checkoutChange(head, d.exec);
  if (changed) {
    d.error(
      `[chreode] the steps changed the checkout (${changed}); ` +
        `commit the change and re-run signoff. Nothing was posted.`
    );
    return 1;
  }

  // 7. Tail
  try {
    runTail(
      {
        sha: head,
        signer: pre.signer,
        noPush: opts.noPush,
        ranLabels: plan.steps.map((s) => s.label),
        skippedByFlag: plan.skippedByFlag,
        allowedStderr,
        baseFlag: opts.base,
        context: config.statusContext
      },
      d.tail,
      d.log
    );
  } catch (err) {
    d.error(`[chreode] ${message(err)}`);
    return 1;
  }
  return 0;
}
```

```ts
import type { BurnInRunner, ResolvedBurnIn } from '../config/types.js';
import type { Exec } from '../run/exec.js';
import { matchesAny } from '../signoff/plan.js';

export class BurnInError extends Error {
  constructor(message: string) {
    super(message);
    this.name = 'BurnInError';
  }
}

/**
 * Paths added or modified in base..head, newest mtime first so the file cap keeps the most
 * recently touched. --no-renames lists a rename as delete + add and --diff-filter=d drops
 * deletions, so a renamed file appears under its new name only. Files missing on disk
 * (mtime null) are dropped.
 */
export function burnInCandidates(
  base: string,
  head: string,
  exec: Exec,
  mtime: (path: string) => number | null
): string[] {
  if (base === head) return [];
  const out = exec('git', ['diff', '--name-only', '--no-renames', '--diff-filter=d', '-z', `${base}..${head}`]);
  return out
    .split('\0')
    .filter((p) => p !== '')
    .map((path) => ({ path, time: mtime(path) }))
    .filter((c): c is { path: string; time: number } => c.time !== null)
    .sort((a, b) => b.time - a.time)
    .map((c) => c.path);
}

/** The first runner that matches the path and does not ignore it. */
export function runnerFor(path: string, runners: readonly BurnInRunner[]): BurnInRunner | null {
  for (const runner of runners) {
    if (!matchesAny(path, runner.match)) continue;
    if (runner.ignore !== undefined && matchesAny(path, runner.ignore)) continue;
    return runner;
  }
  return null;
}

export interface BurnInGroup {
  runner: BurnInRunner;
  files: string[];
}

export interface BurnInPlan {
  groups: BurnInGroup[];
  /** Burnable files past maxFiles: listed, never silently dropped. */
  skipped: string[];
}

export function selectBurnIn(paths: readonly string[], config: ResolvedBurnIn): BurnInPlan {
  const byRunner = new Map<BurnInRunner, string[]>();
  const skipped: string[] = [];
  let kept = 0;
  for (const path of paths) {
    const runner = runnerFor(path, config.runners);
    if (runner === null) continue;
    if (kept >= config.maxFiles) {
      skipped.push(path);
      continue;
    }
    byRunner.set(runner, [...(byRunner.get(runner) ?? []), path]);
    kept += 1;
  }
  const groups = config.runners
    .filter((runner) => byRunner.has(runner))
    .map((runner) => ({ runner, files: byRunner.get(runner)! }));
  return { groups, skipped };
}

export interface BurnInCommand {
  runner: string;
  files: string[];
  command: string;
}

export function burnInCommands(plan: BurnInPlan, repeats: number): BurnInCommand[] {
  const out: BurnInCommand[] = [];
  for (const { runner, files } of plan.groups) {
    const produced = runner.command([...files], repeats);
    const commands = Array.isArray(produced) ? produced : [produced];
    const ok =

          `non-empty array of them`

  return out;

```ts
import { statSync } from 'node:fs';
import type { ResolvedBurnIn } from '../config/types.js';
import { defaultExec, defaultRun, type Exec, type Run } from '../run/exec.js';
import {
  BurnInError,
  burnInCandidates,
  burnInCommands,
  selectBurnIn,
  type BurnInCommand
} from './select.js';

export interface BurnInDeps {
  exec: Exec;
  /** Inherited stdio: the test runners' own output streams through. */
  run: Run;
  mtime: (path: string) => number | null;
  log: (m: string) => void;
}

function mtimeOf(path: string): number | null {
  try {
    return statSync(path).mtimeMs;
  } catch {
    return null;
  }
}

/**
 * Run every test file added or changed in base..head `repeats` times with retries off. The
 * first failure exits 1. All of chreode's own output goes to stdout: this runs inside a
 * policed signoff step.
 */
export function runBurnIn(
  config: ResolvedBurnIn | null,
  range: { base: string; head: string },
  overrides: Partial<BurnInDeps> = {}
): number {
  const d: BurnInDeps = {
    exec: defaultExec,
    run: (command) => defaultRun(command),
    mtime: mtimeOf,
    log: (m) => console.log(m),
    ...overrides
  };
  if (config === null) {
    d.log('[chreode] burn-in: chreode.config.ts has no burnIn block; nothing knows how to run tests');
    return 1;
  }
  const candidates = burnInCandidates(range.base, range.head, d.exec, d.mtime);
  const plan = selectBurnIn(candidates, config);
  let commands: BurnInCommand[];
  try {
    commands = burnInCommands(plan, config.repeats);
  } catch (err) {
    if (err instanceof BurnInError) {
      d.log(`[chreode] ${err.message}`);
      return 1;
    }
    throw err;
  }
  const kept = plan.groups.reduce((n, g) => n + g.files.length, 0);
  if (kept === 0) {
    d.log('[chreode] burn-in: no changed test files; nothing to burn in');
    return 0;
  }
  d.log(`[chreode] burn-in: ${kept} changed test file(s) × ${config.repeats}, retries off:`);
  for (const group of plan.groups) {
    for (const file of group.files) d.log(`  ${file} (${group.runner.name})`);
  }
  if (plan.skipped.length > 0) {
    d.log(`[chreode] burn-in: over the ${config.maxFiles}-file cap, NOT burned in:`);
    for (const file of plan.skipped) d.log(`  ${file}`);
  }
  for (const c of commands) {
    d.log(`[chreode] burn-in (${c.runner}): ${c.command}`);
    try {
      d.run(c.command);
    } catch {
      d.log(
        `\n[chreode] burn-in FAILED (${c.runner}): ${c.files.join(' ')}\n` +
          `[chreode] command: ${c.command}\n` +
          `[chreode] A test that flakes at birth flakes forever: fix it before it lands.`
      );
      return 1;
    }
  }
  d.log('[chreode] burn-in: every changed test file survived');
  return 0;
}
```

import { resolveFlakes, type ResolvedConfig } from '../config/types.js';
import { defaultExec, type Exec } from '../run/exec.js';
import { ghLedgerDeps } from './gh.js';
import type { FlakeLedgerDeps } from './ledger.js';
import { flakeLogPath } from './log.js';
import { escalationMessage, runFlakePhase } from './phase.js';

export interface FlakeReportDeps {
  exec: Exec;
  ledger: FlakeLedgerDeps;
  logPath: string;
  log: (m: string) => void;
  warn: (m: string) => void;
  error: (m: string) => void;
}

/** `chreode flake-report`: the signoff flake phase on its own, for hosted CI or by hand.
 *  Without a `flakes` block it uses the defaults: running it is the opt-in. */
export function runFlakeReport(
  config: ResolvedConfig,
  overrides: Partial<FlakeReportDeps> = {}
): number {
  const d: FlakeReportDeps = {
    exec: defaultExec,
    ledger: ghLedgerDeps(),
    logPath: flakeLogPath(),
    log: (m) => console.log(m),
    warn: (m) => console.warn(m),
    error: (m) => console.error(m),
    ...overrides
  };
  const flakes = config.flakes ?? resolveFlakes({});
  const sha = d.exec('git', ['rev-parse', 'HEAD']).trim();
  let branch = 'HEAD';
  try {
    branch = d.exec('git', ['symbolic-ref', '-q', '--short', 'HEAD']).trim();
  } catch {
    // Detached, e.g. a CI checkout of a sha.
  }
  const outcome = runFlakePhase({
    logPath: d.logPath,
    ctx: { branch, sha },
    config: flakes,
    ledger: d.ledger,
    log: d.log,
    warn: d.warn
  });
  if (outcome.kind === 'none') {
    d.log('[chreode] flakes: no flakes recorded');
    return 0;
  }
  if (outcome.kind === 'reported' && outcome.result.escalations.length > 0) {
    d.error(escalationMessage(outcome.result.escalations, flakes));
    return 1;
  }
  return 0;
}

````markdown
# Flakes

A flaky test is a gate that is not deterministic: the same change gets a different verdict on a
re-run. Re-running is cheaper than fixing, so a suite that "usually passes" quietly stops
selecting anything. Flakes are bugs, not noise. This doc covers the machinery chreode provides
to make them visible and the playbook for killing them.

## The machinery

**Telemetry.** Run your test runners with one retry locally and register chreode's reporters
(see the README). Every test that fails and then passes on a retry is appended to
`.chreode/flakes.jsonl` with the first attempt's error and, for Playwright, the failed
attempt's trace. With retries off there is nothing to record, and the reporters cannot tell
that retries are off: turn them on. Keep pure-logic suites at zero retries; they must not flake
at all.

**The ledger.** With `flakes: {}` in `chreode.config.ts`, signoff reads the log after its steps,
whether they passed or failed, and gives each flaking test exactly one open GitHub issue
labelled `flake`, titled `flake(<kind>): <file> › <title>`. Each later run that sees the same
flake adds an occurrence comment. `chreode flake-report` does the same outside signoff, for
hosted CI or by hand. If GitHub is unreachable the events stay in the log for the next run;
an outage never blocks a merge.

**Escalation.** At 3 recorded occurrences (`flakes.threshold`), any run that sees the flake
again fails until it is fixed. Labelling the issue `flake-snoozed` (`flakes.snoozeLabel`)
defers escalation. Like a stderr allowlist entry, a snooze is a reviewed decision, never a
reflex. A snoozed flake still runs and still records.

**Burn-in.** The `burn-in` step (`burnInStep()`) runs every test file added or changed on the
branch 5 times (`burnIn.repeats`) with retries off, up to 12 files (`burnIn.maxFiles`; the
overflow is listed, never silently dropped). Any failure fails signoff: a test that flakes at
birth flakes forever. Do not run repeat matrices by hand; signoff does it, the same way, every
time. A deflake change touches the test file, so it is burned in automatically.

## The playbook

Work the list top-down. It is ordered by how often each fix turned out to be the real one.

1. **Suspect a product bug first.** If the failure could happen to a slow human on a slow
   device, it is not a test bug. Typical shapes: a form binding re-seeded by a background
   refresh, a reactive draft that discards in-flight edits, a debounced handler that truncates
   submitted text.
2. **Add a deterministic readiness signal.** Assert on an explicit "ready" attribute (for
   example `data-hydrated` or `data-editor-ready`) instead of a poll budget or a fixed tick. If
   the app exposes no signal for the state you need, add one.
3. **Gate the precondition, not the result.** Poll until the precondition of the action is
   observably true before acting, rather than acting and polling for the outcome: result
   polling can settle on a wrong but stable state.
4. **Re-fire until observed**, for one-shot or throttled events (hover reveals, a first
   keypress) that can be missed under load with nothing re-firing them. Only for idempotent
   actions, and in a shared helper rather than an inline poll.
5. **Drive deferred work deterministically.** Timers, alarms and broadcasts have unbounded
   latency under full-suite CPU load: trigger the deferred work from the test instead of
   waiting wall-clock time. A fixture date that arms a real timer must never drift into the
   past, or the timer fires on its own before the test drives it.

**Never:** raise a timeout as the fix; add a fixed wait; write a wait helper that returns
instead of throwing on timeout (it hides the failure and spawns a worse flake later); leave a
flake to "just re-run".

**Scattered timeouts that never repeat the same test** are machine pressure (memory, swap,
stray processes), not test bugs. Check the machine first.

**A same-run cluster is one incident.** When several readiness timeouts from unrelated tests
are filed from one run at one sha, that is machine starvation wearing issue clothing. Before
diagnosing one, check its occurrence comments for same-run siblings. Keep one issue as the
ledger entry, close the rest as duplicates pointing at it, and never "fix" the cluster with
per-test timeout raises.

## Triaging a filed issue

1. Read the first-attempt error and trace in the issue. Reproduce with the burn-in command
   shape: the runner's own command, the one file, retries off.
2. Diagnose with the playbook and fix it in a normal change. State the root cause when closing
   the issue: "re-ran it" is not a close reason.
3. If the fix must wait, label the issue `flake-snoozed` with a comment saying why and when it
   will be picked up. It keeps collecting occurrence comments.

## Root-cause classes

| Class                                                   | Fix                                         |
| ------------------------------------------------------- | ------------------------------------------- |
| One-shot or throttled event missed, nothing re-fires it | Re-fire until observed                      |
| Product bug unmasked by the test                        | Fix the product                             |
| Missing readiness gate                                  | Add a readiness signal                      |
| Layout or geometry not settled                          | Poll for a stable box before acting         |
| Timer or broadcast starvation                           | Drive the deferred work from the test       |
| Soft timeout masking a failure                          | Wait helpers must throw                     |
| Harness or transport not ready                          | Gate on backend readiness                   |
| Environment divergence (viewport, fonts, locale)        | Pin the environment; anchor deterministically |
| Same-run readiness cluster                              | Triage as one machine-starvation incident   |
| Fixture date drifted into the past                      | Relative fixture clocks                     |
````

A test that fails and then passes on retry is a flake, and a flake is a bug. chreode records
each one, files it as a GitHub issue, and fails signoff when the same flake keeps coming back.
The doctrine and the fix playbook are in [docs/flakes.md](docs/flakes.md).

});
```

  test: { retry: 1, reporters: ['default', new VitestFlakeReporter()] }
});
```

Events go to `.chreode/flakes.jsonl` (signoff tells each step the absolute path in
`CHREODE_FLAKE_LOG`, and the sha under test in `CHREODE_HEAD`). Add `.chreode/` to
`.gitignore`; signoff refuses to run otherwise. `playwright` and `vitest` are optional peer
dependencies: the reporters import only their types.

**2. Ledger.** Add `flakes: {}` to the config. After the steps, pass or fail, signoff gives
each flaking test one open issue labelled `flake` (the label is created if missing) and adds an
occurrence comment each time it recurs. At `threshold` occurrences (default 3) signoff fails,
naming the issues, until the flake is fixed or its issue is labelled `snoozeLabel` (default
`flake-snoozed`). A GitHub error is a warning: the events stay in the log for the next run.
`chreode flake-report` runs the same report outside signoff and exits 1 on escalation.

**3. Burn-in.** `burnInStep()` adds a step that runs every test file changed since the base
`repeats` times with retries off, so a new flake fails before it lands rather than after three
victims. Pass your test steps' triggers as `when`, and place it after them:

```ts
import { burnInStep, defineConfig } from '@mindlace/chreode';

export default defineConfig({
  steps: [
    { label: 'test:unit', run: 'npm run test:unit', when: ['unit'], policeStderr: true },
    { label: 'test:e2e', run: 'npm run test:e2e', when: ['e2e'], policeStderr: true },
    burnInStep({ when: ['unit', 'e2e'] }) // timeoutMs defaults to 10 minutes
  ],
  flakes: {}, // threshold: 3, snoozeLabel: 'flake-snoozed', playbookUrl: docs/flakes.md
  burnIn: {
    repeats: 5, // default
    maxFiles: 12, // default; the overflow is listed, never silently dropped
    runners: [
      {
        name: 'e2e',
        match: 'e2e/**/*.spec.ts',
        ignore: 'e2e/helpers/**',
        // Pin a project: --repeat-each multiplies across every project otherwise.
        command: (files, n) =>
          `npx playwright test --project chromium --repeat-each=${n} --retries=0 ${files.join(' ')}`
      },
      {
        name: 'unit',
        match: 'src/**/*.spec.ts',
        // vitest has no --repeat-each: return one invocation per repeat.
        command: (files, n) =>
          Array.from({ length: n }, () => `npx vitest --run --retry=0 ${files.join(' ')}`)
      }
    ]
  }
});
```

A changed file goes to the first runner that matches it and does not `ignore` it; files no
runner takes are not burned in, and deleted files never are. Commands run from the repo root
with inherited output; the first failure fails the step and names the files and the command.

In `vite.config.client-test.ts`, in `test`, after `name: 'client',` add:

    // The server project stays at 0: pure logic must not flake.

```

- [ ] **Step 3: Document it**

At the end of `docs/dev/testing.md`, add:

```markdown
## Flakes

Playwright runs with one retry and the vitest `client` project with `retry: 1`; the `server`
project stays at 0, since pure logic must not flake. A test that fails and then passes on retry
still passes, but chreode's reporters record it in `.chreode/flakes.jsonl`, and signoff files
or bumps one GitHub issue (label `flake`) per flaking test. At three occurrences signoff fails
until the flake is fixed or its issue is labelled `flake-snoozed`. Signoff's `burn-in` step
runs every test file changed on the branch five times with retries off (Playwright: `chromium`
only). Do not run repeat matrices by hand. Diagnose with the
[flake playbook](https://github.com/mindlace/chreode/blob/main/docs/flakes.md).
```
